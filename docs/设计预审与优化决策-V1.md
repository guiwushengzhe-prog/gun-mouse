# 枪型飞鼠 V1：设计预审与已落实的优化

日期：2026-10-06。正式维护分支 `codex/pcb-shell-finish`；本轮从 `e4325bf` 开始。原 AI 分支和工作区保留。下面区分已经完成的文件/几何工作、具体修改方案和真正需要独立判断的事项，不把软件检查通过写成实物已经可用。

本轮结论：现方案可以继续作为设计基线，但在按钮公差与 USB 布局解决前，不应把现有制板包和打印包作为保证完整装配的成品定稿下单。两处局部结构改件已生成，正式原六件打印包没有被覆盖。

局部实体文件在 `deliverables/design-precheck/局部打印候选/`。两个零件均为有效单实体，打印网格单连通，无开放边、非流形边和零面积面。右壳只增加约 280.19 立方毫米材料；扳机只去除约 17.30 立方毫米材料，正式源文件校验值未变。生成入口和局部检查证据随文件保存。

## 二、按钮公差问题已经查清，剩下的是选择具体机构

扳机当前静止高度 17.0、到底高度 12.9，行程 4.1 毫米。开关动作高度按现配置为 12.8～14.4；原厂最少保证的动作后余行程为 1.2。要覆盖最晚动作个体，最终高度应不大于 12.8；要不超过最早动作个体的最低保证余行程，又应不小于 13.2。两个条件没有交集。这不是简单的“补 0.1 毫米”：当前早动作个体压入 1.5 毫米，超出了最低保证范围；并不等于已证明实际损坏。[欧姆龙 SS 规格，第 6 页](https://omronfs.omron.com/en_US/ecb/products/pdf/en-ss.pdf)

我的首选方向是保留壳体硬限位与扳机小板，让驱动触点有可设定位置，由装配方在真实总成上调整、固定后交付。候选目标是动作后压入 0.95±0.1 毫米；仅按开关动作公差，触点相对原位置需要约 -1.15～+0.65 毫米调整。安装基准尺寸、焊接落座、卡槽浮动和打印误差还会扩大范围，不能现在冻结调节长度。可换尖端便宜但增加备件选择；小螺钉可调但需要防松；柔顺传力不需逐件调整，却需要材料、变形和疲劳验证。让 Astra 比较这三种实现，而不是再次查“有没有少 0.1 毫米”。余行程目标依据常开触点的推荐用法，不等于已经完成力学验证。[欧姆龙使用指南](https://www.ia.omron.com/product/cautions/28/precautions_for_correct_use.html)

右键也存在同类边界：现推杆高度 7.47、到底 6.62；公开参数动作高度为 6.9±0.2、最小保证余行程 0.2。早动作个体到底后余行程 0.48，晚动作个体约 0.08。仅用这些保证值不能证明固定行程适合全部个体。准确订货规格与实装基准还需复核；不擅自把 0.85 毫米位移改小就称修好了。[D2FC 原厂规格](https://components.omron.com/us-en/sites/components.omron.com.us/files/datasheet_pdf/B152-E1.pdf)

## 三、USB 布局需要实际重排，已形成两条可落地方向

正式快照中数据正线总长约 149.85 毫米、21 段、无过孔；负线约 155.26 毫米、27 段、2 个过孔且经过两层。还存在约 35 毫米的区段两线分开近 9.8 毫米。正式版无覆铜，缺少连续参考地。重点是两线成对与地回流，不能只盯 5.42 毫米差长，也不能因 12 兆位每秒就直接认定此布局可靠。厂家要求成对布局、参考地及按叠层设计阻抗。[乐鑫 USB 布局要求](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/pcb-layout-design.html)

- **保留底口下载：**先固定两线共同通道，尽量同层成对，并在下方建立连续地参考；必要换层时增加附近地回流孔。向板厂取得两层板实际材料和叠层（铜层与绝缘层厚度），再定线宽/间距。不直接增加到四层，也不把当前 0.15 毫米线宽当成已满足差分阻抗。
- **底口只充电：**取消底部接口到主控的两条长数据线，装壳前把开发板从主板排母拔出，使用开发板自身接口烧录，再断线插回。电路更简单，但以后现场更新要拆壳拔板；如果要解决维护便利，需要单独设计服务入口或另做软件更新方案。这不是本轮已经采用的改动，也不涉及插 USB 自动停用鼠标。

我的偏好是先争取两层板保留底口下载，避免把用户维护变成拆壳。若实际通道和供电隔离代价太大，再选仅充电方案。让 Astra 根据正式布局与成本选定后，再进行真正的电路修改、规则检查和新制造导出。

## 四、电源已完成的核算与最小改进方向

RT9080 额定 600 毫安选型本身没有错，但 USB 供电时约 4.7V 降到 3.3V，平均负载 120 毫安时损耗约 0.168 瓦、250 毫安时约 0.35 瓦。手册热阻来自特定测试板，不能直接当成密闭外壳的温升。TP4056 按约 360 毫安充电，5V 输入、电池 3.0V/3.7V 时自身损耗约 0.72/0.47 瓦；原板没有大片散热铜，必须设计散热路径并确认实际电池充电规格。[Richtek 原厂资料](https://www.richtek.com/assets/product_file/RT9080/DS9080-09.pdf)、[TP4056 原厂资料](https://www.toppwr.com/uploadfile/file/20230304/640301eae1260.pdf)

| 假设整机平均电流 | 假设可用容量为 700mAh 的 80% 时续航 | 360mA 充电加系统及约 3mA 其他负载的 USB 输入 |
| ---: | ---: | ---: |
| 80mA | 7.00 小时 | 443mA |
| 120mA | 4.67 小时 | 483mA |
| 180mA | 3.11 小时 | 543mA |
| 250mA | 2.24 小时 | 613mA |

表是敏感性分析，电流和 80% 比例均未测，不是续航承诺。当前只有两路 Type-C 下拉，不能据此认定已经获准取得更大的输入电流。暂停鼠标输出也不代表主控已不耗电；用户已明确取消插拔 USB 自动暂停/恢复规则，不加入这种交互限制。计算脚本与数据在 `scripts/design_review/summarize_design.py` 和 `evidence/design-review-v1/设计计算.json`。

具体方案先从低复杂度出发：保留负载共享与主控，用电池规格允许的较低充电电流作为首件候选、给充电区增加接地散热铜、确认源端输入预算和稳压热条件。若低电量压降、输入限流或电池温度监测仍无法可靠满足，再比较带负载优先与温度检测的充电管理芯片。阻值、铜面积及新芯片不能在缺电池与厂商参数时直接冻结。降低充电电流也不能冒充完整的输入电流控制。

开发板厂家允许 3.3V 排针供电，因此不直接宣判现架构不可用；但开发板板载稳压输出仍在同一电源线上。接开发板自身 USB 可能引入第二个 3.3V 来源；**只关 SW3 并不隔离主板稳压输出**。首样服务操作应先拔出开发板、断开电池与外部供电，再按单板流程操作。输入检测分压在关机后仍连接电池/USB，隔离是否需加器件是正式供电设计的集中决策，不描述成已烧毁或毫无风险。

触摸保留现铜箔加 GPIO14 的简单方案。下一版建议在主控侧加入约 510 欧姆串联电阻，并保留合适的低电容静电保护位置；这需要实际修改电路与重新导出，尚未落实到正式板。不要给触摸信号随意并上 100nF。整机触摸、软线移动和充电干扰需要样件确认。[乐鑫触摸硬件建议](https://documentation.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/schematic-checklist.html)

## 五、采购与首件测量不再丢给 Astra 猜

| 项目 | 已知关系与具体动作 |
| --- | --- |
| 电池 | 仓宽 31、长 53、深 8.4；最大占位 8×31×52.5 对应厚隙 0.4、宽隙 0、长隙 0.5。优先约 6×30×52 含保护板候选，但采购应给实体最大尺寸、线头和极性；测打印仓后确定正间隙和固定材料 |
| 压簧 | 当前静止安装长 13.1、到底 9.0；要求供应商给两位置载荷、刚度、材料、圈数、并圈高度和安全压缩。不逐根剪短，不猜弹力 |
| 开发板 | 核对实物版本、排针针长、塑料肩部、板厚、屏蔽罩及插座最高点；使用厂家已有尺寸，不重复测能直接查图的尺寸 |
| 摇杆 | 实测安装高度、按下和摆动空间、帽子保持力；RKJXV1224005 原厂已列为新设计非推荐品，不等于停产。首样可保留，批量需确认替代型号与供货 |
| 电极与线束 | 供应商预制单触摸导体，工厂端接与应力固定；测实际接头高度和全行程软线，不让用户夹铜箔裸线。新局部腔仍需确认实样 |
| USB 插头 | 用实际带包胶的插头试开口与插拔，固定脚必须全部焊好。现有附近螺柱可保留，没有证据要求重新移动插座 |

天线方面已知道原参数 X≥52 区域里有 C5/C6 和 11 段线路，但这个数值约定还不是实际馈点/天线净空。要对照真实开发板天线和厂家图确定铜/结构避让，不能为了满足自己猜的区域删去去耦电容。这与供电、USB 新地参考的布局调整合并判断。

## 六、交给 Astra 的剩余范围

只集中审核：按钮公差吸收机构的选型与实现、电源/充电/关机隔离的最小架构、USB 通道与参考地及天线的共同布局、批量摇杆的替代与是否独立组件。输入、装配清单、已有工具修复和重复软件规则检查不是主要审核工作。

本轮没有重排正式主板、没有增加触摸串阻或替换电源器件，没有将候选打印件改名覆盖原件。配置只校正文字说明，网络与几何参数没有变化；原制板数据保留便于比较。下一轮应围绕剩余架构决策完成真实改板和按钮改件，再与实测参数一起形成新定稿。
