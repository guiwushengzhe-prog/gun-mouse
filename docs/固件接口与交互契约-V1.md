## 已确定并实现的规则

- 触摸只允许惯性鼠标移动；左右键、中键与摇杆都独立。
- 触摸保持、机械松开时左键释放，体感继续；完全离开时立即丢弃尚未发送的体感位移。
- 重新触摸时，以惯性采样队列当时的尾序号为起点，不发送离开期间的积压样本；重复和旧序号不再处理。
- 惯性芯片未就绪时仅停止体感，不影响实体按键和摇杆。
- 断线时不累计移动；重新连接首帧全键释放、位移为零，后续按实际当前输入报告。
- **USB 插拔没有自动暂停、恢复鼠标的规则。**用户明确取消了这个限制；USB 检测与交互核心分开。

采样层要持续读取惯性芯片，触摸关闭时仍消费并丢弃旧数据。允许体感后，积分的时间差也从新样本开始；不能把关闭期间的整段时间乘进第一帧位移。发送层还要清除自己的旧体感缓存和小数余量，不能只清核心里的缓冲。

## 采样方式已经确定

| 功能 | 接口 | 首轮实现约束 |
| --- | --- | --- |
| 摇杆 X/Y | IO4/IO5 | 模拟采样；测中心、两端和死区，分别归一化两半行程，不假设计数满量程恰好等于 3.3V |
| 摇杆中键 | IO6 | 低有效；独立按键去抖 |
| 右键、扳机左键 | IO15/IO16 | 低有效；独立去抖，触摸状态不改按键状态 |
| 触摸铜箔 | IO14 | ESP32-S3 触摸时读数上升；32 位读数。整机装壳、实际线束与不同供电状态分别测基线，不复制原 TTP223 的数字读取方式 |
| 惯性芯片 | IO8/IO9，地址 0x6A | 两线总线；SA0 接地，CS 上拉；中断 IO10/IO11。芯片轴向必须映射到 X 向前、Y 向左、Z 向上 |
| 电池检测 | IO1 | 校准后的模拟电压乘 2；1M/1M 分压和 100nF 对采样稳定时间有影响，等待稳定再读，不把电压直接线性当电量百分比 |
| USB 电压检测 | IO2 | **校准后的模拟电压读取**，最高衰减档；首轮可用进入 1.5V、退出 1.2V 的迟滞门限（两个门限之间保留原状态），实测后确定 |

IO2 的分压在 USB 为 4.75V 时只有 2.375V，而 3.3V 供电下保证数字高电平需要约 2.475V，因此不依赖 `digitalRead`。`UsbDetector` 已实现模拟门限参考逻辑，但没有调用真实模拟采样接口。该改法不解决关机时输入来自外部电源的隔离问题。[乐鑫芯片资料](https://documentation.espressif.com/esp32_s3_datasheet_en.pdf)

Arduino 官方当前列出的 S3 最高衰减档测量范围至 3.1V；芯片数据手册的校准精度条件至约 2.9V。两者描述的是不同保证，不能因此假定 3.3V 摇杆端部保持全量程精度。GPIO14 的合法性与 S3 触摸读数方向已核实。[模拟采样接口说明](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/adc.html)、[触摸接口说明](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/touch.html)

## 后续集成必须完成的接口工作

1. 核心方法在同一线程调用，或由外部串行保护。序号在核心生命周期内单调递增；惯性驱动重启后不能直接归零继续复用旧核心。
2. `takeReport()` 会消费运动与首帧释放，只在发送层能接受时取报告。发送失败时不能无条件重放过期体感；触摸释放后要撤销尚未发出的体感分量，实体按键变化和摇杆分量另行保留。
3. 参考核心只保留最新按键状态。发送层必须保存去抖后的按下、释放变化，避免两次发送之间完整点击被吞掉；断线后不重放旧连接的按键队列。
4. 蓝牙鼠标整数位移转换要保留小数余量，并处理报告范围，避免每帧截断精细移动。触摸释放清体感小数余量，摇杆小数余量独立。
5. 实现真实触摸基线、阈值、干扰抑制和重新校准；实现惯性静止零偏与轴向映射；再接蓝牙连接和发送。灵敏度、去抖时长及死区由样件体验决定，不假装已经测好。

这些是正式固件尚未完成的清单，不需要 Astra 重做引脚核对和简单状态逻辑；后续固件开发可直接使用本文件与参考核心，但不能把电脑上的逻辑检查称为硬件验收。

## 固件实现说明（2026-10-06）

- 体感方向：芯片 Z 轴等于整机左向轴，俯仰直接用它；偏航取“绕重力竖直方向的转动”，竖直方向由开机静置校准和加速度计低通得到，因此不依赖芯片 X/Y 在板上的朝向。方向反了可用串口 `invx`、`invy` 调整。
- 触摸：S3 触摸读数上升为触摸；开机约 0.4 秒建立基线，未触摸时缓慢跟踪，开机时正好在摸会在松开后自动重建基线。门限取“基线比例”和“噪声倍数”中较大者，按下需稳定 3 毫秒，松开立即生效。比例初值 2.0%/1.2%，装壳后用 `log` 观察读数再用 `tp`、`tr` 调整。
- 按键：按下立即生效、松开稳定 3 毫秒；发送层保存每次状态变化逐个发送，两次发送之间的完整点击不会丢；断线清空，不重放。
- 摇杆：开机取中心，两端分别归一化并在使用中自动扩展，`jsave` 保存；`jdir` 向导确定方向；回中清摇杆小数余量。
- 电源：IO1 读电池，IO2 用模拟电压判断 USB；只用于电量显示和低电保护，不暂停鼠标。未插 USB 且电池低于 3.3 V 持续 30 秒时进入深睡，按扳机或 10 分钟定时唤醒复查。
- 设置保存在开发板非易失存储，串口命令见 `deliverables/evt-a/README.md`。
