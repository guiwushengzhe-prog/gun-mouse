# 枪型飞鼠 V1：工厂装配与交付要求

编写日期：2026-10-06。用途：采购、工厂询价及首件装配分工，不是已下单、已获得工厂承诺或可量产的证明。

适用正式设计：`pcb/gun-mouse-v1/`、`config/pcb-shell-v1.json`、`deliverables/pcb-shell-v1/`。自动布线试验工程不用于采购、焊接或产品交付。本文件不改变电路、器件位置和外壳模型。

本轮预审发现按钮全公差与 USB 布局尚需修改；本文件先供范围询价，制造放行前须采用解决这些条件的新定稿，不能把报价确认当成设计验收。已核实结论及剩余方案见 `docs/设计预审与优化决策-V1.md`。

目标是让用户到手后插上已预制线束、装入机构件并拧螺丝；板上焊接、分板、端子压接、电极端接尽量提前完成。哪些步骤由嘉立创、线束供应商或独立装配方承接，要在询价回复中明确，不把全部项目自动归入普通贴片订单。

## 二、给制板与装配方的询价要求

1. 使用同一版的制板压缩包、物料清单和坐标文件；回复主板、扳机小板的实际焊接套数。电路板为两层、1.6 毫米、1oz（每平方英尺一盎司铜），当前正式版保持原无覆铜走线。
2. 文件含主板与扳机小板两款不同电路，确认拼板款数、异形外轮廓、邮票孔、工艺边、光学定位点和装配夹持方式。若需工程加工艺边，先给出修改稿；保持两块成品板的安装孔、槽口和配合板边，不可为了上机擅改成品尺寸。[嘉立创制造工艺要求](https://www.jlc.com/portal/1/serviceGuide)按板形或电路等差异计算拼板款数，并说明邮票孔分板会留下齿状边缘。
3. 按上表逐项回复“可供料并焊接 / 客供料可焊接 / 缺料 / 无法承接”，尤其单独回答 J1、J2、SW1、SW2、SW3、SW4、USB1。未选入焊接订单的器件不能按已采购或已焊接计算；官方下单说明也区分已选择的贴装和插件范围。[嘉立创贴片下单教程](https://m.jlc.com/portal/q7i19326.html)
4. 询价焊接后分板、邮票孔残余毛刺处理、清除加工粉尘和按套包装。扳机小板需要直接插入壳内卡槽，分板方法不能压弯板、划伤元件或焊点，板边不得有妨碍入槽的残余连接桥。去毛刺后的允许残余量尚需首样与卡槽配合确定，不虚构未验证公差。
5. 分板处理完后，再确认元件没有损伤、板没有翘曲，按一块主板加一块小板为一套包装；保护摇杆轴、微动杠杆和插座，不能在运输中持续顶压摇杆。Alps 原厂要求使用时焊接全部金属支撑脚，并提醒轴持续受力的包装可能影响性能。[Alps 原厂产品说明](https://tech.alpsalpine.com/e/products/detail/RKJXV1224005/)
6. 工厂的外观或焊点检查不能代替蓝牙、体感、触摸、充电和整机装配验证。若能承接烧录和功能检查，单独报工装、调试、逐台加工费用，以及客户需提供的程序和操作文件；不要把这些费用当成贴片费已包含。

嘉立创官方列有分板出货、清洁和额外包装等个性化服务，但其分板介绍不足以确认本版邮票孔处理、去毛刺、电极预装和整机装配都可承接。未列出的项目需专门询价；价格和可承接范围以本次订单回复为准。[嘉立创个性化服务说明](https://www.jlc.com/portal/q7i40512.html)

## 四、烧录、校准和出货检查的交付请求

以下是要求承接方报价并确认的产品服务，尚未形成已经验证的逐台工艺。没有对应可用固件、测试工具和首件标准时，不能要求工厂凭硬件文件保证功能。

- 烧录资料：给出最终程序文件、版本与校验值、对应硬件版本、写入位置、工具及操作步骤。确认底部 USB1 实际可下载；若新开发板首次下载需要 BOOT/RESET（启动/复位）按键操作，应在合壳前由装配方完成，并确认后续维护方法。
- 校准资料：首件确定惯性芯片坐标映射、静止零偏处理、摇杆中心与死区、触摸基线与阈值策略；列出哪些参数逐台保存、哪些由固件自动处理。不得把某一台裸板触摸阈值复制为所有已装壳产品的合格标准。
- 合壳前检查：核对 48 个器件、焊点和机械固定；插入开发板；验证电源开关、USB 通信与下载、惯性芯片读取、摇杆双轴及按下、右键和机械扳机触点。将具体测试电压、电流和判定门限交给电气及固件首件验证后填写，不凭猜测承诺数值。
- 合壳后检查：用目标固件确认蓝牙鼠标配对；轻触扳机仅开放体感位移，继续按压触发左键，释放机械按压但保持接触时左键释放且体感继续，完全离开时体感停止；实体按键和摇杆不受触摸关闭影响，重新触摸不集中发送旧位移。再检查摇杆连续摆动与中键、右键、扳机回弹、线束未夹紧和充电口插拔。
- 电源检查：首件确认充电、电池供电、插拔 USB、低电量及系统负载下的供电与温升，确定可复用的方法。插拔 USB 不自动停用/恢复鼠标，不以这种规则绕过输入电流与散热设计；使用开发板自身 USB 的单板服务操作要先将开发板从主板排母拔出。
- 出货记录：硬件版本、程序版本、器件替换清单、烧录结果、校准方式/结果、板级及合壳后功能结果；未通过项目单列，返修后重查相关功能。若仅承接焊接，应明确写“板级焊接交付”，不能标成“整机已可使用”。

## 五、缺料与以后小批量的处理原则

首样按现有正式设计采购，不把所有器件都重新选一次。已有、可直接减轻用户工作的确定项先落实：完整工厂焊接、成品端子线、正确极性的插接电池、分板与去毛刺询价、触摸组件预装询价和逐项责任表。

缺料时要求返回原位号、原编号、候选编号、数据手册及库存/交期，经过电气、封装和机械核对后再批准。排母不能仅凭 2.54 毫米针距与 8.5 毫米高度替换；不同触点结构、壳体外形、针长和配合公差都会影响开发板及外壳。SS-01GL、SS-01GL13 不能仅因同系列就视作同一杠杆结构。GY-601N1 飞线备份属于需要手焊并重新固定模块的调试方案，不能替代缺 U1 的完整工厂交付。

RKJXV1224005 当前原厂状态为“新设计不推荐”，厂家说明该类产品仍面向既有设计供应，并非已停产。首样可沿用以保留当前封装和外壳；批量前必须确认可持续供货与替代器件。替代摇杆可能需要修改焊盘、轴高、摇杆帽、安装结构甚至局部主板，不能承诺只换一个打印支架即可。[Alps 原厂供应状态](https://tech.alpsalpine.com/e/products/detail/RKJXV1224005/)

之后的批量优化应比较整机装配用时、需手工加工的步骤、供应周期、返修更换难度和总成本。直接焊主板与独立摇杆小板、插座开发板与直接贴装模组等方案先做具体成本和受力比较，再决定是否重新制板或打印。当前不自动增加功能按键或零件，也不把“免焊”说成“免装配、无需校准、一次打印必定成功”。
