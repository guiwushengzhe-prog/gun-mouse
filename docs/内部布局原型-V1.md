# 内部布局原型 V1

日期：2026-10-05。目标：在现有外形方向内说明组件放置、支架与线束；不是制造定稿。当前主控为已有 ESP32-S3，使用内置电容触摸，省去 TTP223。

## 放置建议

| 部件 | 放在哪里 | 原因与安装关系 |
| --- | --- | --- |
| ESP32-S3开发板 | 上壳纵向，天线朝前端塑料区域 | 夹边托架承托板边，不使用未经确认的板上孔；主板与伸出天线分开表示；开发板下载口作为拆壳维护接口，不冒充电池充电口 |
| 普通PS2摇杆 | 上壳后部左侧，部分嵌入壳内 | 右手拇指可达；独立安装座；整体突出量与帽摆动计入厚度；此件较大，不画成微型摇杆 |
| 鼠标右键 | 摇杆下方拇指可达区 | 独立输入；选型及位置未冻结，需避免推动摇杆时误压 |
| GY-601N1惯性模块 | 手掌上方中段，主控下方的独立刚性夹持台 | 与扳机微动承力支架分开，不以未核对孔位作固定依据；不能固定在容易弯曲的薄盖上；传感器轴向后续单独映射 |
| SS-01GL与扳机帽 | 扳机后方的固定件 | 帽推动短杠杆；壳体限位承受过行程；未按照片建立孔位 |
| 铜箔电极 | 小打印扳机帽内侧 | 与金属微动结构绝缘；一根短柔性线直达S3触摸通道；留运动余量和固定点 |
| 700mAh电池 | 握把中下段 | 独立绝缘托槽，接头可拆；固定与线路不挤压软包；没有实测质量，未验证重心 |
| 充电与供电模块 | 握把底部规划区 | 底部Type-C向外，插座需支撑插拔力；电路与完整板型仍待验证 |

先采用这个共同布局生成内部透视、分解安装和触摸/线束三张图，不在每张图随意换位置。左右半壳、主控托架、摇杆安装座、惯性托台、微动固定件、电池托槽是装配意图；其曲面、螺丝柱和公差后续才定。

分解图中间区域为概念支撑骨架，承接各托架，不是第三片外壳。后续可以把相应支撑并入一侧半壳或做成独立内架，取决于打印、拆装及刚性需求。当前安装示意不能用于推断电路板需要钻孔；未确认的孔位仍为空。

## 尺寸证据与参考区域

开发板主板平面57.15×27.94毫米、含天线整体长63.39毫米，来自用户公制图；高度未给。惯性模块标称17.8×20.6×2.8毫米，来自用户说明书；焊好排针的高度未知。SS-01GL壳体19.8×6.4×10.2毫米及14.5毫米杠杆来自对应原厂图，但端子、导线和操作空间不包含在壳体尺寸中。

普通PS2摇杆使用Joy-IT同类模块34×39×26毫米作参考区域；电池使用DNK同容量型号47×25×6.5毫米作参考区域。它们不代表已购DZYJ摇杆和现有电池，不称为通用标准，也不由这些参考值建立实物固定孔。电源、右键、扳机帽和主控高度采用本轮设计预留体积，明确与真实尺寸分开保存。

本轮壳体厚度探索值40毫米；摇杆参考区从左侧伸出，规划区域总宽至少49毫米，尚未核实实际帽、摆动和安装座。这个结果提示后续需要保留厚度调整空间，不能声称整机就是40毫米厚。

用户认为普通摇杆较大，本轮仍保留已购模块。查到[Adafruit 2765迷你双轴摇杆](https://www.adafruit.com/product/2765)17.5×17.4×12毫米和[Adafruit 444 PSP式摇杆](https://www.adafruit.com/product/444)19×19×9毫米，均有自回中但没有按下开关；裸件需要焊线或小转接板。它们仅为以后换装的尺寸对照，未采购、不加入本轮模型，国内供货及价格未核对。换用时需另解决中键，不能直接保持五针模块全部功能。

## 线束关系

- 铜箔→S3专用电容触摸输入，选脚和阈值待配置。触摸线走靠近主控的短路线，活动段留余量，避开限位、壳缝、天线和升压部件。
- 微动常开触点→独立数字输入与地，负责机械左键，电气负载和去抖后续确定。
- 普通摇杆→两路模拟输入及独立按压中键；右键→独立数字输入。
- 惯性模块→主控，保留直接读取传感器芯片路径，接口和针号尚未分配。
- 电池→充电及供电电路→主控和外围。底部插口为电池充电口；开发板自带口用于维护，不按外观推断充电管理功能。

图中的连线是功能关系及走线方向，不是最终原理图、线长或针脚表。主控、各模块按最终电路共地，不能并接未经核对的稳压输出。

## 可重新生成的占位参考

`config/internal-layout-v1.json` 保存所有布局建议，统一X向前、Y向左、Z向上。原点为上壳与握把交界附近的概念点。真实尺寸、引用其他厂商的参考尺寸、设计预留区域分别标记。

`scripts/build_internal_layout.py` 通过现有CadQuery（程序化实体建模工具）和离屏绘图生成布局参考，输出位于 `outputs/internal-layout-v1`。运行命令：

```powershell
$env:PYTHONUTF8 = '1'
& 'E:\GunMouseCAD\CadQuery\python.exe' 'F:\项目\枪型飞鼠\scripts\build_internal_layout.py'
```

布局参考可导出STEP（实体三维交换文件），不生成最终STL（三角网格打印文件）、焊盘或安装孔。参考盒之间的空隙或重叠只描述规划，不能代替实物装配、握持、天线性能、触摸稳定性或重心验收。新三张效果图位于 `concepts/v3`；效果图负责说明结构，配置与占位参考负责保存这一轮位置。

`concepts/v3/内部布局占位.step`、`参考-左侧占位.png`、`参考-三维占位.png`及`占位检查报告.json`保存本轮参考结果。三维文件中的透明外形是包络、透明盒是规划区域，不是已开模或可直接打印的外壳；主控未知高度用预留盒表示。微动与扳机帽规划盒存在少量重叠以表达按压关系，实际杠杆、帽形及机械行程尚未验证。
