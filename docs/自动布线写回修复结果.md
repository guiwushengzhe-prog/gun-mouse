## 根因及修法

1. 软件连接刷新会删除长度小于0.1密耳的独立导线，即约0.00254毫米。三条丢失线正好全部低于此门槛。直接创建后马上回读已不存在，先创建较长线再改短同样被删除。
2. 将短段用公开接口创建为单段折线，保持相同端点、网络、铜层、线宽和锁定属性。软件把它作为完整路径保存，不受独立短导线清理影响。快照增加第二版格式，将普通线与单段折线统一展开为实际线段后核对；旧格式仍支持。多段折线、曲线和圆弧不在本轮支持范围，遇到会明确拒绝。
3. 另发现厂商折线“按图层读取全部对象”接口的索引错误：元数据筛选后，路径却仍从筛选前数组按原位置取，导致短线编号搭配板框路径。改为无参数读全部对象，再在本地筛层；没有修改厂商安装文件。
4. 连接刷新可能重新分配导线编号。本轮13段确实换了编号，已逐段证明几何及网络属性匹配后更新映射；不能把编号变化或数量相同直接当成成功。

软件内部长度单位为密耳，1密耳等于0.0254毫米。原生文件以0.0001密耳量化坐标和线宽，核对仅允许半个量化单位加浮点余量，即0.000051密耳；本轮最大偏差约0.00000127毫米。网络、层、锁定与类型等属性保持严格相同。原正式板回写和新格式再次回写的最大偏差均为零。

制造铜层采用毫米坐标、五位小数，即0.00001毫米的格式分辨率；与源快照核对容许原生文件和制造格式的合计量化误差。全部500段匹配，三条短段的圆形线宽描画命令和约0.15/0.3毫米实际线宽都存在。这里“短”说的是连接被切分后的线段长度，不是极细线宽；这些段是整体铜图形的一部分，软件清理门槛不能当作工厂制造极限。
