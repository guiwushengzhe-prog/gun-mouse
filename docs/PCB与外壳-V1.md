# PCB 与外壳 V1：设计记录

日期：2026-10-05。原设计分支：`claude/pcb-shell-v1`；独立收尾分支：`codex/pcb-shell-finish`，基线 `dff2043` 保留原成果。目标是首轮打样能完整装配，尽量插接和工厂贴装、少手工焊接。首轮装配和免焊接均为目标，不能仅凭文件检查承诺；交付件及装配说明见 `deliverables/pcb-shell-v1/README.md`。

2026-10-06 实质预审发现按钮固定行程不能用原厂最低保证参数覆盖全公差，以及 USB 数据线布局需要重排；现包不作为已经解决这些条件的成品定稿。局部支撑及电极端接候选、具体决策和计算见 `docs/设计预审与优化决策-V1.md`。下述几何与网络仍描述原正式基线，配置只纠正文字说明。

## 总体结构

主板竖放在机身中面（XZ 平面，顶层朝左 +Y），既是电路板也是骨架：

- 开发板通过两排 1×22 排母插在主板左侧，天线朝前，伸出主板外，前方 x>52 不覆铜。
- 摇杆、右键微动、惯性芯片、充电与稳压电路、底部 Type-C、电源拨动开关都直接装在主板上，计划由工厂贴片或插件。USB1 为混合贴片/插装封装，需与其他插件一起确认工厂的装配范围；工厂承接全部器件后才能按免手工焊接准备。
- 扳机微动装在一块"扳机小板"上。小板与主板拼在同一块板材上，用邮票孔连接；收到后掰下，竖插进两半壳的卡槽，与扳机滑杆正对。
- 电池贴在主板背面（-Y），由右半壳的电池仓和适合厚度的固定材料压住；电池线从主板过线槽穿到正面的 PH2.0 座。仓深 8.4 毫米，约 6 毫米厚电池可配 1～2 毫米泡棉，8 毫米厚电池仅余约 0.4 毫米，不应另加该厚泡棉。
- 两半壳的分壳面与主板元件面重合（y = -1.63）。5 颗 M2×20 自攻螺丝从右侧穿过螺柱和主板孔拧入左侧螺柱，同时夹紧主板；另有 2 颗只连接外壳。

整机坐标沿用内部布局 V1：X 向前、Y 向左、Z 向上，原点为上机身与握把交界概念点。PCB 数据坐标 u = -X、v = Z。所有数值保存在 `config/pcb-shell-v1.json`，脚本只读这一份配置。

## 相对原方案的改动与理由

| 改动 | 理由 |
| --- | --- |
| DZYJ 摇杆模块改为 Alps RKJXV1224005 本体（立创 C146170） | DZYJ 没有尺寸资料，无法保证首轮装上；RKJXV 有原厂图（摆角 23°、Ø4 削边轴），工厂焊接后由主板定位 |
| GY-601N1 模块改为主板贴装 LSM6DSV16XTR（C5267406） | 与模块内是同一颗芯片，可沿用芯片驱动，但固件引脚与轴向需按本板适配；随主板刚性固定，不用焊排针 |
| 未知充电升压板改为板上 TP4056 + 负载共享 P-MOS + RT9080-3.3 | 原模块型号和尺寸未知；锂电直接稳压到 3.3V，比先升压到 5V 再降压更省电；底部 Type-C 兼作 ESP32-S3 原生 USB 下载口 |
| 扳机微动用 SS-01GL13（SS-01GL 同系列，模拟滚轮杠杆） | 立创可采购，工厂按插件焊接；SS 系列按压方向垂直于安装板，所以单独做竖立的小板 |
| 扳机改为直线滑动；握把前缘改为接近竖直 | 原轮廓前缘约 49° 斜面，绕销转动的扳机无法同时满足 4 毫米行程和壳内触点；直线滑动时手指行程等于触点行程 |
| 机身顶面由 z=39 提高到 43 | 竖放的开发板宽 27.94 毫米，需要约 30 毫米内部净高 |
| 板间连接改用 PH2.0 贴片座 + 成品端子线 | 2.54 排针加杜邦头太高，会碰到左壳内壁；PH2.0 双头线可直接购买；扳机两线接反不影响功能，触摸座两脚同网络 |
| 触摸线座放在上机身开发板后方 | 触摸线约 5 厘米，不经过握持区，避免手握握把时误触发 |
| 扳机输入 2.2k 上拉，右键 3.3k 上拉 | 增大触点电流，避免仅靠芯片内部弱上拉；原厂最低负载参考包含 5V/1mA，当前 3.3V 不能只凭达到 1mA 就称满足全部条件，仍需触点稳定性验收 |

## 电路要点

- 供电：Type-C VBUS → TP4056 充电（PROG 3.3k，约 360mA，实际电池是否允许此电流需核对）；VBUS 经 B5819W、电池经 AO3401A 负载共享到 VSYS；RT9080 稳压 3.3V（600mA），EN 由拨动开关控制。关机整机电流尚未实测，检测分压仍连接外部电源，不能只用稳压器关断电流代表整机。3.3V 接开发板 3V3 排针，厂家允许这种供电；板载稳压输出仍在同一电源线上，开发板自身 USB 供电的互斥关系需处理。
- USB：Type-C D+/D- 经 USBLC6-2SC6 接 IO20/IO19（原生 USB），可直接下载固件；CC 两路 5.1k 下拉。
- 电池电压：1M/1M 分压到 IO1；USB 插入检测：100k/100k 分压到 IO2，明确用校准后的模拟电压判断。插拔 USB 不自动暂停或恢复鼠标。参考交互核心及接口契约见 `docs/固件接口与交互契约-V1.md`。
- 惯性芯片 LSM6DSV16X：I2C 地址 0x6A（SA0 接地），SDx/SCx 接地，CS 接 3.3V，SDA/SCL 4.7k 上拉，INT1/INT2 到 IO10/IO11。
- 摇杆两路 10k 电位器接 3.3V/GND，输出到 IO4/IO5（ADC1）并各加 100nF；按下开关到 IO6。

完整引脚表见 `config/pcb-shell-v1.json` 的 `firmware_pins`。

## 布线

原开发的嘉立创专业版 4.1.66 后台会话遇到三处工具问题：从原理图导入变更返回成功但未导入、原生自动布线挂起且板上无走线、覆铜填充重建报错。因此沿用原设计的程序替代流程；本轮未将原生自动布线或覆铜计算宣称为已修复：

1. 接口放置器件、板框、开槽、孔、丝印；
2. 按配置网表直接改写工程文件 `.epcb2` 的 `PAD_NET` 记录，编辑器自动重载后逐一核对；
3. 用同一配置程序生成原理图（48 个器件、160 个已连接引脚）；本轮修正引脚朝外引线方向，消除原先 33 组跨过器件两端、带冲突网络标签的导线，恢复正确原理图；
4. `scripts/pcb_shell_v1/route_grid.py` 两层网格布线：信号 0.15、电源与地 0.3，线距 0.13，焊盘/过孔间距 0.165，定位孔 0.32；惯性芯片电源脚先连去耦电容和 CS 上拉；
5. 写回嘉立创时先建过孔再建导线（导线只在创建时与端点处已有对象建立连接），走线分批写入（命令行长度限制）；
6. 对齐 48 个器件唯一编号，补回原理图阻容值与采购属性，统一原理图板层和 PCB 通道编号；官方接口导出软件编译原理图网表，与配置及刷新后的 PCB 网表逐引脚、编号、封装和采购身份核对一致；
7. 嘉立创规则检查（JLCPCB 两层板工艺）最终为 0 条错误。原提示包含真实原理图错误和同步属性差异，不能解释为仅未建立关联。

本版不铺铜，地网络由导线完整连通。收尾仅修正原理图表达和同步元数据，PCB 的器件位置、旋转、板层、封装及走线保持原设计。后续修改电路时，仍需重新同步网表、规则检查并导出；地网络连通不等同于 USB、天线或触摸抗干扰已经实测。

原理图编译网表改用官方 `sch_ManufactureData.getNetlistFile` 接口，已成功导出嘉立创网表和通用文本格式网表，解决了此前读取超时所导致的无法核对问题。离线实际引线核对脚本为 `scripts/pcb_shell_v1/audit_netlist.py`；软件编译网表比较、最终规则检查和原设计保持证据随交付的 `验证记录/` 保存。

## 外壳与机构

- 壁厚 2.4，外缘倒圆 6；两半壳都按外表面朝下打印。
- 主板四周与内壁留 0.8 毫米；主板孔处螺柱上下夹紧；上板条背面另有 3 个支撑柱。
- 开发板模组屏蔽罩上方有 2 根防脱柱，间隙 0.9 毫米。
- 摇杆开口为锥形：杆身倾斜 20° 时碰到开口内缘，低于原厂 23° 极限；帽盘离壳面约 5 毫米，倾斜时不碰壳。
- 右键帽：内翻边挡住外脱；按下 0.85 毫米时帽沿落到壳面，此时微动已过动作点且在超行程范围内。
- 扳机：滑杆从握把前壁窗口伸入，杠杆触点从静止 17.0 移到 12.9（距小板面），微动动作位 12.8～14.4，行程 4.1 毫米。按到底时滑杆下段后端面撞上弹簧座（硬限位）；复位时尾部凸齿顶住顶导轨后端面。压簧（外径 4、自由长 15）放在滑杆后部孔内，配合微动杠杆复位。动作位置取极端 12.8 毫米的个体，12.9 毫米限位仍相差 0.1 毫米，不能保证触点闭合；全公差下的动作后余行程也未验证。本轮保留该机构，实际开关和打印件需要确认，需要调整时另行说明。
- 触摸面盖厚 0.9 毫米，面盖以外叠层余量约 0.15 毫米。铜箔、薄胶层及剥线接触处需共同试装，不能把面盖顶起，不应使用 1～2 毫米泡棉固定面盖。

## 仍需实物确认

- 开发板：排针朝下、针长不小于约 5.5 毫米，顶面元件高度不超过约 3.5 毫米（外壳按这些值留空间）。
- 电池：603048 型（带 PH2.0 插头）为采购参考，连同保护板和线头的实际尺寸需核对；最大占位为 8×31×52.5 毫米。仓深 8.4 毫米，8 毫米厚电池不能另加 1～2 毫米泡棉，约 6 毫米厚电池才有该厚度的余量。插头极性必须先用万用表核对。
- 摇杆帽实际为双削边孔，圆孔径 Ø4.2 毫米、对边距 3.2 毫米，对应 Ø4/对边距 3.0 毫米的轴；打印偏紧或偏松时改 `joystick.knob.d_hole_clearance`，只需重打帽子。当前配合仍需实测。
- 拨动开关拨到哪一侧是开机，以首次上电时开发板电源灯为准。
- 天线性能、触摸阈值、扳机手感、握持舒适度、整机重心都需要实物测试，模型检查不能代替。
- 文件检查和几何限位验证不是首件装配、上电、充电、USB 通信及开关动作验收；尚未验证的尺寸和公差不能据此称为一次打印到位或直接量产。
