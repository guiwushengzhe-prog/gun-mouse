# PCB 与外壳 V1：设计记录

日期：2026-10-05。分支：`claude/pcb-shell-v1`。目标：首轮打印即可完整装配；尽量插接和工厂贴装，少手工焊接。交付件及装配说明见 `deliverables/pcb-shell-v1/README.md`。

## 总体结构

主板竖放在机身中面（XZ 平面，顶层朝左 +Y），既是电路板也是骨架：

- 开发板通过两排 1×22 排母插在主板左侧，天线朝前，伸出主板外，前方 x>52 不覆铜。
- 摇杆、右键微动、惯性芯片、充电与稳压电路、底部 Type-C、电源拨动开关都直接装在主板上，由工厂贴片或插件。
- 扳机微动装在一块"扳机小板"上。小板与主板拼在同一块板材上，用邮票孔连接；收到后掰下，竖插进两半壳的卡槽，与扳机滑杆正对。
- 电池贴在主板背面（-Y），由右半壳的电池仓和泡棉压住；电池线从主板过线槽穿到正面的 PH2.0 座。
- 两半壳的分壳面与主板元件面重合（y = -1.63）。5 颗 M2×20 自攻螺丝从右侧穿过螺柱和主板孔拧入左侧螺柱，同时夹紧主板；另有 2 颗只连接外壳。

整机坐标沿用内部布局 V1：X 向前、Y 向左、Z 向上，原点为上机身与握把交界概念点。PCB 数据坐标 u = -X、v = Z。所有数值保存在 `config/pcb-shell-v1.json`，脚本只读这一份配置。

## 相对原方案的改动与理由

| 改动 | 理由 |
| --- | --- |
| DZYJ 摇杆模块改为 Alps RKJXV1224005 本体（立创 C146170） | DZYJ 没有尺寸资料，无法保证首轮装上；RKJXV 有原厂图（摆角 23°、Ø4 削边轴），工厂焊接后由主板定位 |
| GY-601N1 模块改为主板贴装 LSM6DSV16XTR（C5267406） | 与模块内是同一颗芯片，固件相同；随主板刚性固定，不用焊排针 |
| 未知充电升压板改为板上 TP4056 + 负载共享 P-MOS + RT9080-3.3 | 原模块型号和尺寸未知；锂电直接稳压到 3.3V，比先升压到 5V 再降压更省电；底部 Type-C 兼作 ESP32-S3 原生 USB 下载口 |
| 扳机微动用 SS-01GL13（SS-01GL 同系列，模拟滚轮杠杆） | 立创可采购，工厂按插件焊接；SS 系列按压方向垂直于安装板，所以单独做竖立的小板 |
| 扳机改为直线滑动；握把前缘改为接近竖直 | 原轮廓前缘约 49° 斜面，绕销转动的扳机无法同时满足 4 毫米行程和壳内触点；直线滑动时手指行程等于触点行程 |
| 机身顶面由 z=39 提高到 43 | 竖放的开发板宽 27.94 毫米，需要约 30 毫米内部净高 |
| 板间连接改用 PH2.0 贴片座 + 成品端子线 | 2.54 排针加杜邦头太高，会碰到左壳内壁；PH2.0 双头线可直接购买；扳机两线接反不影响功能，触摸座两脚同网络 |
| 触摸线座放在上机身开发板后方 | 触摸线约 5 厘米，不经过握持区，避免手握握把时误触发 |
| 扳机输入 2.2k 上拉，右键 3.3k 上拉 | SS-01 与 D2FC 都是微负载触点，最小可靠电流约 1mA；芯片内部弱上拉只有几十微安 |

## 电路要点

- 供电：Type-C VBUS → TP4056 充电（PROG 3.3k，约 360mA，适合 700mAh）；VBUS 经 B5819W、电池经 AO3401A 负载共享到 VSYS；RT9080 稳压 3.3V（600mA），EN 由拨动开关控制，关机时只剩微安级漏电。3.3V 接开发板 3V3 排针，不经开发板 5V 和板载稳压器。
- USB：Type-C D+/D- 经 USBLC6-2SC6 接 IO20/IO19（原生 USB），可直接下载固件；CC 两路 5.1k 下拉。
- 电池电压：1M/1M 分压到 IO1；USB 插入检测：100k/100k 分压到 IO2。
- 惯性芯片 LSM6DSV16X：I2C 地址 0x6A（SA0 接地），SDx/SCx 接地，CS 接 3.3V，SDA/SCL 4.7k 上拉，INT1/INT2 到 IO10/IO11。
- 摇杆两路 10k 电位器接 3.3V/GND，输出到 IO4/IO5（ADC1）并各加 100nF；按下开关到 IO6。

完整引脚表见 `config/pcb-shell-v1.json` 的 `firmware_pins`。

## 布线

嘉立创专业版 4.1.66 在后台会话中有三处不可用：从原理图导入变更（返回成功但不导入）、自动布线（挂起，板上无走线）、覆铜填充重建（`rebuildCopperRegion` 内部报错）。因此流程为：

1. 接口放置器件、板框、开槽、孔、丝印；
2. 按配置网表直接改写工程文件 `.epcb2` 的 `PAD_NET` 记录，编辑器自动重载后逐一核对；
3. 用同一网表程序生成原理图（48 个器件、160 个引脚连线），并把 PCB 器件唯一编号对齐到原理图；
4. `scripts/pcb_shell_v1/route_grid.py` 两层网格布线：信号 0.15、电源与地 0.3，线距 0.13，焊盘/过孔间距 0.165，定位孔 0.32；惯性芯片电源脚先连去耦电容和 CS 上拉；
5. 写回嘉立创时先建过孔再建导线（导线只在创建时与端点处已有对象建立连接），走线分批写入（命令行长度限制）；
6. 嘉立创规则检查（JLCPCB 两层板工艺）：间距与连通性错误为 0，仅剩"原理图与 PCB 未建立导入关联"的网表提示。

本版不铺铜，地网络由导线完整连通。今后在界面里修改电路时，可以从原理图导入（器件按唯一编号对应），也可以手动加铺铜后重新导出。

## 外壳与机构

- 壁厚 2.4，外缘倒圆 6；两半壳都按外表面朝下打印。
- 主板四周与内壁留 0.8 毫米；主板孔处螺柱上下夹紧；上板条背面另有 3 个支撑柱。
- 开发板模组屏蔽罩上方有 2 根防脱柱，间隙 0.9 毫米。
- 摇杆开口为锥形：杆身倾斜 20° 时碰到开口内缘，低于原厂 23° 极限；帽盘离壳面约 5 毫米，倾斜时不碰壳。
- 右键帽：内翻边挡住外脱；按下 0.85 毫米时帽沿落到壳面，此时微动已过动作点且在超行程范围内。
- 扳机：滑杆从握把前壁窗口伸入，杠杆触点从静止 17.0 移到 12.9（距小板面），微动动作位 12.8～14.4，行程 4.1 毫米。按到底时滑杆下段后端面撞上弹簧座（硬限位）；复位时尾部凸齿顶住顶导轨后端面。压簧（外径 4、自由长 15）放在滑杆后部孔内，配合微动杠杆复位。

## 仍需实物确认

- 开发板：排针朝下、针长不小于约 5.5 毫米，顶面元件高度不超过约 3.5 毫米（外壳按这些值留空间）。
- 电池：推荐买 603048 型（带 PH2.0 插头）；现有电池若不超过 8×31×52.5 毫米也可以用。插头极性必须先用万用表核对。
- 摇杆帽 D 形孔按 Ø4.1/削边 3.1 设计；打印偏紧或偏松时改 `joystick.knob.d_hole_clearance`，只需重打帽子。
- 拨动开关拨到哪一侧是开机，以首次上电时开发板电源灯为准。
- 天线性能、触摸阈值、扳机手感、握持舒适度、整机重心都需要实物测试，模型检查不能代替。
