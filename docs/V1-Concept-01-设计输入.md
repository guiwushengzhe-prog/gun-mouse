# 枪型飞鼠 V1-Concept-01：当前设计输入

记录日期：2026-10-05。统一单位：毫米。当前阶段：概念外观及器件参数调查，正式器件清单和制造尺寸未冻结。

## 当前交互

右手单手握持、手枪外形、低功耗蓝牙鼠标。IMU（惯性测量单元，即加速度计和陀螺仪）负责精细瞄准，普通 PS2 五针电位器摇杆负责连续大角度转向，摇杆按下为鼠标中键。

| 食指状态 | 体感移动许可 | 机械左键 |
| --- | --- | --- |
| 未接触扳机 | 关闭 | 由微动开关独立决定 |
| 轻触扳机表面，未按压 | 开启 | 释放 |
| 继续按压，微动闭合 | 开启 | 按下 |
| 松开机械按压，但仍接触 | 开启 | 释放 |
| 完全离开扳机 | 关闭 | 由微动开关独立决定 |

触摸与机械点击是两个独立输入。关闭体感时丢弃待发位移；关闭期间不积累位移，重新接触时不集中发送旧位移。实体左、右、中键和摇杆功能不依赖体感许可。此处描述的是软件目标，尚未编写或验证本项目固件；真实抬指响应包含检测器延时，需实测。

独立右键先放在右手拇指可接触的控制区；鼠标“右键”指功能，不要求装在外壳右侧。用户已说明主要单独点击，不要求持续按住右键并同时推动摇杆。最终位置通过握持测试确定。中指、无名指、小指用于稳定握持。

当前不使用握把触摸区、轨迹球、触摸滑动、实体滚轮或新增功能按键。第一版明确使用已购普通 PS2 模块，不采用购物记录中的 PS4/PS5 摇杆或磁阻摇杆。

## 外形与坐标

探索包络初值：长 180、最大厚 40、高 135 毫米。允许探索范围分别为 160～200、35～50、120～150 毫米，以真实电子器件、握持及装配要求为准。普通壳壁厚先探索 2～2.4 毫米；触摸面独立做多种厚度测试件。以上均不是制造定稿。

用户已于 2026-10-05 确认采用右手坐标系：X 向前、Y 向左、Z 向上。PCB（印制电路板）、所有模块、支架和外壳在正式建模时必须共用这些轴方向及同一原点；原点位置在整体布局时确定。

## 结构约束

1. 左右可拆卸半壳，优先螺丝连接；螺丝柱、孔位和公差在实际工艺及样件确认后确定。
2. 触摸扳机帽、电极和微动固定件独立可维护。外壳机械限位承担过行程力，不能由微动开关承受全部手指压力。
3. 建议试验薄塑料触摸面下贴铜箔电极，电极随帽移动，检测板固定在壳内，用短柔性引线及转轴附近余量连接。该方案是待验证的工程建议；现有 TTP223 模块能否可靠引出外接电极须检查实物。
4. 惯性传感器设置独立刚性固定区域，避免直接承担扳机或壳缝的连接应力。其具体位置待结构和振动评估。
5. 普通 PS2 摇杆设置独立安装座；以后通过重做局部支架适配其他型号，不保证直接互换。
6. 电池独立绝缘安装，使用可维护连接，预留必要空间；不焊死在电路板上，不把电池尺寸或固定压力凭空定稿。
7. Type-C 口预留实际插头、线材和插拔空间。效果图表示充电口位置，不承诺新增有线鼠标功能。
8. 主控天线周边空间待准确模块和天线规范确认，避免不合理的电池、金属遮挡；不使用任意统一禁布距离。
9. 不根据照片比例臆造板尺寸、安装孔或焊盘。同名模块尺寸不视为通用。未经实测的区域只作概念布局。

## 2026-10-05：尺寸资料与低成本扳机补充

用户提供的两个压缩包已完整解压到 `器件资料/原始资料`；常用图纸复制到 `器件资料/参考图纸`，保留原始资料和根目录压缩包。

ESP32-S3 资料图给出主板 57.15×27.94 毫米、含伸出天线总长 63.39 毫米；不把总长全画成主板矩形。GY-601N1 说明书标称 17.8×20.6×2.8 毫米。采用这些资料名义尺寸继续布局，同时把实际板版本、含排针及插头的三维占用、安装孔等未给出的数据留空。尺寸图和 ESP32-S3 V1.4 电路图的局部器件位置不能默认一致。

用户提出 SS-01GL 上贴铜箔检测触摸，优先简单、便宜。当前原型复用 SS-01GL、铜箔和已有 TTP223。可以在金属柄上隔一层绝缘胶带再贴电极；更舒适的结构建议是小打印扳机帽内贴铜箔、帽压微动，随外壳一起打印。两种安装方式的选择尚未回复，不将其冻结为最终结构。

铜箔接现有触摸板确认后的感测节点，触摸板状态输出和微动开关分别接主控。不能把模块三针中的输出脚当成电极端。感测线短、柔软、留回弹余量；跟随触摸而不是每次触摸切换保持状态；原型验证按压全过程和抬指响应。不要求为此先购买新的触摸检测器。
