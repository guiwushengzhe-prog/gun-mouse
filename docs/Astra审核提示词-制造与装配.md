## 补充审核：从文件到可用实物

1. **固件与首次使用。**确认是否已有可交付的固件（运行在主控上的程序），还是目前只有引脚说明；列出烧录、配对和校准还缺什么。核对触摸与机械点击独立、离开触摸后不积压鼠标位移、摇杆大幅转向与惯性精细瞄准的配合、传感器轴向，以及断线重连后的按键释放。触摸阈值是否能适应手指差异、充电干扰和扳机活动？先审核缺口，不在本轮编写整套固件，也不把电路规则通过当成功能已完成。
2. **免掰板、免修磨的交付。**现说明要求用户沿邮票孔（小板与主板之间便于折断的连接孔）掰下扳机小板并用砂纸磨毛刺。比较工厂完成分板、去毛刺后交付与主板、小板分别制造的方案，判断分板应力和剩余板边是否影响器件与卡槽。优先取消用户自己掰板和修磨，明确哪些只需调整拼板或采购安排，哪些需要改板形或外壳。
3. **按压和插拔的受力。**主板还承担内部骨架作用，摇杆与惯性芯片装在同一板上。检查摇杆按下、扳机按到底、充电插拔和拧螺丝时，力是否由壳体及支撑承担，是否让主板弯曲、焊点受力或影响惯性测量。优先比较局部壳体支撑的最小改动；只有必要时才调整器件位置或电路板。
4. **续航、发热与供电余量。**根据实际开发板、700mAh 电池、线性充电和稳压电路，估算蓝牙正常使用、低电量和边充边用时的电压、电流与封闭外壳内发热，核对外部充电口和开发板自带接口之间的供电关系。给出合理的续航范围与假设，不能仅凭稳压器额定 600mA 就认定够用；没有实测就标为估算，并指出最少还需测什么。
5. **工厂检查与最少用户步骤。**明确每块板装壳前如何上电和检查，整机如何烧录、校准与验证；必要的测量位置是否容易接触，能否减少为了检查而反复拆壳。只在确有价值时建议增加测试焊盘或简易定位结构。比较当前方案和推荐方案各需用户做哪些操作，逐项标出可由工厂或预装供应商完成的工作；不要把用户少焊接变成更多夹线、修磨或调试。

下单前还缺哪些关键实测尺寸，请按优先级列出最小清单，说明测哪里、会影响哪些零件。至少覆盖开发板含排针的高度、电池含保护板及线头的占位、扳机开关动作与复位位置、摇杆按下及摆动空间、真实充电插头和打印配合；已有可信图纸的项目不要求无意义地重复测量。
