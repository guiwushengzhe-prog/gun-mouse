当前手焊小元件已从15颗精简到8颗：保留 `R_TRIG、R_TOUCH、R_BAT_H、R_BAT_L、C_TRIG、C_BAT、C_JOY_X、C_JOY_Y`。保留电量显示；取消低电量自动休眠、外部供电识别及其3颗元件，摇杆按下和右键改用芯片内部上拉及软件消抖，省去对应4颗元件。保留的8颗元件通孔从0.8毫米增至1.1毫米、铜焊盘从1.6毫米增至2.6毫米，元件分行拉开；电阻脚距7.62毫米、电容脚距5.08毫米保持，不改变模块原有排针间距。`BOM.csv`、源板和三维模型已同步；旧制造压缩包未改。

完整装配模型中已确认摇杆在拇指面、开发板及陀螺仪在另一面；**源板目前仍保留上一轮模块孔位和孔号，翻面及摇杆新五针孔尚未同步，整个源板未重新布线，不可下单制造**。当前只用于查看装配结构。

## 接线与电源

沿用现有SS金属扳机，两根线连接公共端与常开端；右键使用原微动，摇杆保留原生帽。铜箔触摸电极经R_TOUCH连接，铜箔与金属摆杆绝缘。

电池正极接J_BAT，经SS12D10 G5拨动开关后接SuperMini专用B+；负极共地接专用B−。拨动开关相邻脚距4.7毫米，使用1.8毫米孔和3毫米焊盘。电池仍采用带保护板的602060单节锂电池，按20×80×8毫米外形空间试装。

本版保留电压估算电量，取消低电自动休眠及外部供电识别。充电或电池开关关闭而USB供电时，B+节点读数可能偏高，不能作为充满判断。

原有SuperMini供电路径限制继续适用：接电脑前关闭电池开关；电池开关打开时充电使用已通电的USB电源，关闭外部电源前先关闭电池开关。完全断电需要关闭电池开关并拔下USB。

旧打板压缩包、嘉立创工程、接线表和检测报告未随本轮结构更新。当前源板尚无走线，待模块安装面、摇杆新孔同步并完成布线后再导出制造文件。
