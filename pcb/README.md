# PCB 模块装配预览

当前手焊小元件已从15颗精简到8颗：保留 `R_TRIG、R_TOUCH、R_BAT_H、R_BAT_L、C_TRIG、C_BAT、C_JOY_X、C_JOY_Y`。保留电量显示；取消低电量自动休眠、外部供电识别及其3颗元件，摇杆按下和右键改用芯片内部上拉及软件消抖，省去对应4颗元件。8颗元件改为每行一颗、左右交错，通孔1.1毫米、铜焊盘2.6毫米，每颗两孔均拉开至10.16毫米；模块排针间距保持。8颗之间最小孔中心距约6.17毫米、铜盘边缘间隙约3.57毫米；与邻近开关等其他焊盘最小铜边间隙约3.19毫米。物料清单、源板和铜层三维模型已同步。

完整装配模型和源板现已同步：摇杆在+Y拇指面，开发板、陀螺仪及其他板上元件在−Y面；摇杆帽仍朝+Z。真实孔号随模块实体旋转，摇杆五针由原竖排改为横排，整机X坐标从小到大依次为接地、3.3伏、横轴、纵轴、按下；五孔Z坐标均为5毫米。配置中的 `model_reference_pads` 仅供装配模型构造原始实体，`pads` 才是实际制板坐标，不能再次翻转它们。


## 当前文件

- 源板：gun-mouse-supermini-carrier.kicad_pcb；物料清单：BOM.csv。
- 裸板三维模型：3d/gun-mouse-gen2.obj，与同目录材质文件配套使用。完整装配模型见 ../shell/README.md。
- 板材为玻璃纤维环氧板，52×82毫米外接尺寸，保留原缺口；板厚1.6毫米、双面铜层。四个M2安装孔直径2.4毫米。
- 当前模块排针孔距保留：SuperMini两排各9孔、GY左8右6孔，排针脚距2.54毫米。SuperMini两排间距15.24毫米仍为暂定值。

| R_TOUCH | 510欧，触摸电极串联 |
| R_BAT_H、R_BAT_L | 各100千欧，电池电压减半采样 |

电阻本体不超过6.4×2.6毫米；陶瓷电容本体宽不超过6毫米、厚2毫米、焊后高7毫米。可沿用原元件，将引脚向外成形到10.16毫米孔距；电容在离本体一小段距离处弯腿，不能从根部硬掰。模块自带排针间距不改。焊后剪脚伸出板面不超过1毫米。

## 接线与电源

沿用现有SS金属扳机，两根线连接公共端与常开端；右键使用原微动，摇杆保留原生帽。铜箔触摸电极经R_TOUCH连接，铜箔与金属摆杆绝缘。

电池正极接J_BAT，经SS12D10 G5拨动开关后接SuperMini专用B+；负极共地接专用B−。拨动开关相邻脚距4.7毫米，使用1.8毫米孔和3毫米焊盘。电池仍采用带保护板的602060单节锂电池，按20×80×8毫米外形空间试装。

本版保留电压估算电量，取消低电自动休眠及外部供电识别。充电或电池开关关闭而USB供电时，B+节点读数可能偏高，不能作为充满判断。

原有SuperMini供电路径限制继续适用：接电脑前关闭电池开关；电池开关打开时充电使用已通电的USB电源，关闭外部电源前先关闭电池开关。完全断电需要关闭电池开关并拔下USB。

实际双面网络已完成24条连接、11个过孔；同名KiCad制造压缩包、接线表和检测报告已重新导出。带本次实际封装的导出环境检查为0错误、0警告、0未连接；保留的仓库旧封装库与新板上封装不同，在本机原工程检查会显示17条库版本不一致警告，仍为0错误、0未连接。未覆盖已有封装库，也未更新E盘旧嘉立创原生工程或其旧制造包。尺寸暂定、模块供电、实际焊接及功能仍需样机确认。
