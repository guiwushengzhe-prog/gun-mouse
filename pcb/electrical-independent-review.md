## MCU 电气角色

|功能|GPIO|电气角色|
|---|---|---|
|JOY_X / JOY_Y|1 / 2|ADC1 模拟输入，最高衰减档；输入端不启用内部拉电阻。|
|JOY_SW / BTN_R|4 / 12|机械低有效输入，可保留内部上拉作未连接载板时的备援。|
|TRIG|8|机械低有效输入及 RTC 深睡唤醒；GPIO8 支持该用途。|
|SDA / SCL|5 / 6|I²C 双向开漏；总线由 GY 模块上拉到模块内部 3.3V。|
|TOUCH|7|ESP32-S3 触摸通道；不作数字按钮输入，不启用上/下拉。|
|VBAT_ADC / VBUS_DET|9 / 10|ADC1，分别读取开关后电池节点与共享供电轨的二分之一电压。|

全部功能 GPIO 不重复。配置保留 GPIO3、43、44，未占用原生 USB GPIO19/20，也未占用启动配置 GPIO0/3/45/46。参考 SuperMini 中 GPIO3 已接板载共享 VBUS 分压，不应作为独立空闲 GPIO。固件头文件与配置对应；代码只对三个机械按键开 `INPUT_PULLUP`，四 ADC 使用 `ADC_11db`；原生 USB CDC 编译条件避免物理 UART0 占用。没有把原 YD 或 XIAO 固件引脚套用到 SuperMini。

## 电源约定与实物边界

电池正极从 J_BAT 1/BAT_RAW，经 J_SWITCH 两焊点接外置 SPST，再从 BAT_SW 到 J_MODULE_BAT 1/模块专属 B+；负极接 GND/B−。BAT_RAW 未直接连接 ADC，电池分压在隔离开关后；该网络能够避免关掉电池、同时拔 USB 后，未隔离的电池继续经该分压向 MCU 注入电流。**不可把 BAT_SW 改接模块 5V 脚。**

开关 OFF 同时断开电池充电和放电；插 USB 时控制器仍能运行。完全断电需 OFF 并拔 USB。OFF+USB 时 BAT_SW/B+ 是空载充电器 BAT 端，可能约 4.2V，不是实际电池端电压；固件及说明已明确这点。

两组 100k/100k 分压具有 50k 等效源阻抗、100nF 电容，时间常数均为 **5ms**，约 25ms 后达到通常可用的稳定程度。定时唤醒的 50ms 等待及多次平均足够覆盖这个 RC，但仍应实板比较万用表与校准 ADC。4.2V 电池对应 2.1V ADC，5.25V USB轨对应 2.625V ADC；正常单节/USB范围内不会把 5V直接送进 MCU。ADC 内部拉电阻必须保持关闭。

参考 SuperMini 电池经 BAT60B 二极管连接共享 VBUS，再经 ME6217 3.3V LDO。板上没有把 USB-C VBUS 与电池供电的共享轨作反向隔离，也没有电芯放电保护 IC。因而有以下实际限制：

1. 连接电脑前关电池；电池 ON 充电只使用已通电的外部 USB 电源；该外电源断电或关闭前也应先关电池。这个使用条件不能写成硬件已经消除 USB 回馈。若需要任意插拔/掉电都无回馈，仍需硬件反向隔离设计。
2. 使用带过充、过放、过流保护的成品 1S 电池。BOOST 保持开放，100mA 是参考卖家默认档，实际芯片及电阻批次需测充电电流和终止行为；没有证明某个未知批次就是精确 100mA。
3. 电池 3.6V、持续 30秒的深睡阈值是二极管+LDO 的初始供电余量约定，不是电池保护阈值，不能保证 BLE 峰值电流下始终有足够 3V3。需测满电、中等电量、接近低压阈值时的 3V3 与复位情况。
4. 共享 VBUS 在电池模式也有电压。GPIO10 分压 ADC 的 4.5V进入/4.3V退出，仅推断外部5V；USB线路压降、ADC误差或不同板型可能影响判断。不能宣称这是 USB物理插入、充电中或充满检测。
5. 铜箔绝缘、线束固定与短触摸线仍有必要。510Ω 串阻不是完整 ESD 防护，未做整机静电或供电切换抗误触实测；载板暴露允许被握持时，仍应避免手直接接触电池/电源焊点。

上述引脚和器件库网络检查不代替实物验收。到货后在无电情况下确认 B+/B−、5V/USB VBUS、二极管方向和保护电池极性；上电测3V3、分压、充电与关断电流。若与家族图不同，应先修改该批次的接线/电源定义，不能仅凭“SuperMini”商品名直接套用。
