# 飞鼠扩展状态回报

原升级状态保留原接口。扩展状态通过同一管理服务中编号为 `a38b0005-62da-4c13-9f07-908d8b921571` 的加密只读特征读取，每200毫秒更新。单次状态不超过512字节。

`joy`、`power`、`sens`、`imu_ready`、`seq` 和 `cmd` 继续供网页读取。`power.charge=-1` 表示没有硬件充电反馈，不能从电压推断正在充电。

3.2.2起的 `perf` 是最近一个约1秒窗口：`ms` 为实际窗口毫秒，`loop_us` 为最长主循环间隔，`gap_us` 为最长陀螺仪采样间隔，`imu` 为采样次数，`i2c` 为传感器总线读失败次数，`sent` 为蓝牙栈接受次数，`fail` 为蓝牙栈拒绝次数，`link_us` 为实际连接间隔，`edges` 为触摸状态变化次数。3.2.3增加 `err`，正数为底层错误码，负数表示没有单独底层错误码时的回调错误种类，0表示该窗口未记录错误。3.2.4移除已完成排查的触摸读取耗时字段，为按键计数留出容量。

3.2.4增加 `btn` 数组，按下表的位置读取。所有按下、松开及队列满计数都在65535后回到0；差值按65536循环计算，重启后从0开始。

| 数组位置（从0开始） | 含义 |
| --- | --- |
| 0 | 当前扳机原始输入，1为按下 |
| 1 | 去抖后的按键状态，位0为左键，位1为右键，位2为中键 |
| 2 | 主板读到的左键按下次数 |
| 3 | 主板读到的左键松开次数 |
| 4 | 蓝牙栈接受的左键按下次数 |
| 5 | 蓝牙栈接受的左键松开次数 |
| 6 | 当前排队的按键状态数量 |
| 7 | 按键队列装满而合并末项的累计次数，断开连接清队列时仍保留此证据 |
| 8 | 最近被蓝牙栈接受的按键状态 |

一次完整测试应在扳机松开时读取起点，实际按下并松开若干次，再在完全松开且队列清空后读取终点。先对比实际操作次数与主板计数，再对比主板计数和蓝牙接受计数。蓝牙栈接受不表示电脑、模拟器或游戏已经处理，仍需结合电脑输入观察和用户反馈。

3.2.5增加 `boot` 数组：第0项为本次启动至今的毫秒数，第1项为开发核心记录的启动原因。为保持单次回报容量，本版移除 `perf.edges`。启动时间倒退、按键计数同时清零时，应先按发生了重启处理，不得把差值取模后的巨大数值当作点击次数。

启动原因中，1为上电复位，3为软件重启，4为程序异常，5、6、7分别是不同类型的运行超时保护复位，9为欠压复位，14为供电扰动复位。正常更新也会产生软件或下载复位；上电复位本身不能区分用户操作电源开关与供电完全瞬断，必须结合测试操作和实际供电条件判断。含义以[乐鑫系统接口说明](https://docs.espressif.com/projects/esp-idf/en/v5.5/esp32s3/api-reference/system/misc_system_api.html)和当前锁定开发核心的枚举为准。

3.2.6增加 `always`：1为陀螺仪常开，0为触摸控制。此设置独立保存，断电保留。按住扳机和右键重启主控并继续保持约2秒，切换一次模式；两键全部松开前，组合动作不会作为左右键点击发送。只在开机时两键已按下才识别，正常游戏中的同时按键不切换。USB插着时，仅关闭电池开关不会重启主控，需要主控复位或断开并恢复USB供电。串口和蓝牙管理命令 `imu 1`、`imu 0` 分别设置常开和触摸控制。

常开模式仍等待陀螺仪校准，并遵守断线清空、方向校准及升级暂停规则；不会增加惯性传感器的原有采样频率。触摸读数继续报告，但不再控制体感开关。

## 3.3版独立甩拳接口

在原管理服务追加 `a38b0006-62da-4c13-9f07-908d8b921571` 事件通知，以及 `a38b0007-62da-4c13-9f07-908d8b921571` 加密参数读写。原有状态、升级和鼠标报告的编号、格式及设置保持不变，状态中的 `build` 为 `3.3.0`。

通知恰好20字节，小端序：版本1字节、类型1字节、就绪标志2字节、启动随机代号4字节、甩拳序号4字节、设备毫秒4字节、强度2字节、配置代号2字节。类型0为心跳、1为新动作；就绪标志最低位为传感器有效，次低位为拳击可用。强度单位是千分之一倍重力；序号循环计算，不从累计差值补发动作。设备每秒发送一次心跳，动作只即时发送一次；发送位置排在原鼠标报告之后。

参数恰好8字节，小端序：版本1字节、开关1字节、触发强度2字节、冷却毫秒2字节、配置代号2字节。版本固定1，开关0或1，强度1300至3000、冷却250至2000毫秒。主机每5秒续期，15秒无续期停用；相同参数续期不重置冷却。设备仅保存运行时参数，长期保存和游戏绑定由 MotionControl 管理，未连接软件默认停用。

甩拳复用已有陀螺仪和加速度样本，不增加传感器访问。先静稳150毫秒，连续12毫秒达到强度且角速度不小于每秒80度才发一次；之后经过冷却并重新静稳才解锁。采样中断、校准、失效和升级期间不累计进度。电脑按配置代号、启动代号、序号和设备时钟拒绝旧动作，断线释放按键；事件不直接作为蓝牙鼠标键发送。

2026-10-27：新版已编译且170项纯逻辑检查通过。实机原先读回3.2.6、常开启用和摇杆停用；后来设备未开机，无线连接超时发生在开始传输之前。按用户要求先完成电脑端，本版尚未更新到实机。真人触发、回弹、鼠标手感及游戏接收均待设备开机后验收，不能以编译或电脑模拟替代。
