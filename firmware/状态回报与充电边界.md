# 3.2.1 摇杆与供电回报

本版基于运行中的3.2，只增加回报、命令确认与网页显示，不移植第三版试制的触摸、装配或体感算法。不更改已保存设置的结构，蓝牙更新只写非运行的应用分区。

原状态特征`a38b0004-62da-4c13-9f07-908d8b921571`及升级协议保持兼容；扩展状态使用同一管理服务下的只读特征`a38b0005-62da-4c13-9f07-908d8b921571`，沿用已认证、加密连接要求。

| 字段 | 含义 |
| --- | --- |
| project / schema | 项目标识与扩展回报格式版本，当前为gunmouse及1 |
| joy.enabled | 摇杆开关，0停用、1启用 |
| joy.ready | 中心有效、当前允许摇杆输出；启用但中心异常时仍为0 |
| joy.raw / joy.center | 两轴原始值和最近中心；停用时原始值0表示没有采样，不代表两轴实际接地 |
| joy.speed / joy.rev / joy.middle | 推满速度、取中心修订号、消抖后的中键状态 |
| sens / imu_ready | 实际体感灵敏度与陀螺仪是否已完成校准 |
| seq / cmd | 主循环已认可并处理的命令序号与名称；重启后从0开始 |
| power.mv | 现有GPIO9分压采样换算的开关后连接点电压，单位毫伏；尚无有效采样时为-1 |
| power.charge | 当前恒为-1，表示没有硬件反馈，无法判断充电状态 |

扩展回报每200毫秒复用已有读数，不新增模拟采样；命令处理后提前刷新，网页每秒读取。缓冲区512字节，桌面逻辑检查覆盖最大合法参数与计数边界及缓冲不足时拒绝输出，避免回报截断成无效数据。

电池开关关闭时，采样点与电池断开，数据线供电仍可能使该点电压升高。开关打开时也没有充电电流或充电芯片状态输入，因此不得将有外接电源、电压升高、电量百分比或程序串口连接解释为充电已确认。此前万用表4.0/4.1伏与串口约5.07伏不一致，网页将偏高采样单独标明，不能用本次遥测改动掩盖采样误差。

准确报告正在充电、充满等状态需要把充电芯片的状态信号接入可读输入，并核对电平。本版没有擅自复用已有焊盘、将空闲引脚当作已接线，或改动已下单主板。
