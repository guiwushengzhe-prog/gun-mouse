# 第二代开放工程样机

当前装配以拇指所在一面为操作面：HW-504摇杆仍在这一面；一体支架和电池托换到主板小元件一面，薄护板挡住八颗手焊电阻电容，右键、电源拨柄及金属扳机保持外露可操作。上方SuperMini开发板和陀螺仪的位置不变、不额外包覆。摇杆轴平行主载板，原生帽沿整机 +Z 朝天空。电池所在的下半段作为握持位置，不增加塑料扳机、摇杆帽或外部限位圈。

摇杆外形按 [DZYJ尺寸图](../器件资料/原始资料/HW-504双轴摇杆模块_DZYJ尺寸图.jpg) 的标称值建模：黑板33×27毫米，安装孔距26.4×19.5毫米，原孔直径3.3毫米，含原生帽总高约30毫米。图注尺寸误差0.5～1毫米；轴心、排针弯角和帽形仍为外形示意。

尺寸取舍以商品图明确标注为准，19.5×26.4毫米孔距不是实物测量值。图中未标排针中心线到近侧安装孔中心线的间距，此项用用户实测约2.4毫米补充；旧模型的1毫米只是估算。当前弯针模块及固定短柱相应向外移动1.4毫米，主板原五孔保持不变。

靠主板的两个安装孔以19.5毫米间距固定在一体底座的两根短柱上。使用两颗 **M2×10螺丝和普通M2螺母**，**不需要新增垫片**。塑料座一孔为2.4毫米圆孔，另一孔为沿孔距方向的2.4×3.6毫米短槽。摇杆模块与短柱整体降低4毫米，让原有弯排针及塑料条位于小板上面，针脚向下穿过小板、在其底面焊接；主板五孔保持不变。连接短臂由主板原缺口绕到拇指面，不穿过电路板。

底座连接梁绕开黑板、原生帽和运动空间，给拇指从上方接近帽子留空，不构成额外限位。模块相对电池中线向前偏4毫米。底座只有一个打印实体，按树脂密度估算约16.5克；不是实物称重。

电池仓仍为2.4毫米厚的外围框、中央纵筋和分段横筋，留两列共10个圆角小窗，窗宽6.8毫米。两条侧梁宽2.3毫米、深11.1毫米，内侧距电池名义包络各0.5毫米、开放面高出电池0.5毫米；根部以圆角三角筋接入支撑。仓外宽保持25.6毫米。电池及托架换侧后整体下移12毫米，避开主板底端电源开关，原来的20×80×8毫米电池包络不变。放入面和上端出线口敞开，两条绑带穿侧壁窗口，槽上保留实体桥；没有实测承载力数值。

四根主板固定柱随支架放在元件面，安装孔保持不变；H2保留贴近主板的短柱，使用M2×10，其余三处继续用M2×20，螺母在拇指面。

载板保留8颗手焊小元件，改为每行一颗、左右交错。通孔1.1毫米、铜焊盘直径2.6毫米，每颗两脚间距均为10.16毫米；可沿用原元件并将引脚向外成形。八颗之间最小孔中心距约6.17毫米、铜盘边缘间隙约3.57毫米，与相邻开关等其他焊盘最小铜边间隙约3.19毫米。程序保留估算电量显示，取消低电量自动休眠与外部供电识别。

## 装配

1. 裸载板先从支架上方滑入，H2用一组M2×10与M2螺母固定，另外三处用M2×20与M2螺母。小元件和模块由侧面送入敞开腔体，最后向主板直插，在拇指面焊接；不要把已经焊满器件的板强行从正面压过摇杆短臂。
2. 开发板与GY模块保持原位置，板间留3毫米。SuperMini两排中心距仍为暂定15.24毫米；模块背面正负极保留两根短线。SS-01GL改用两组已有M2×10和原有垫片固定在换侧后的支承上，仍直接操作金属摆杆。
3. 摇杆放在两根短柱上，用两颗M2×10由下向上固定，上方轻锁M2螺母；两孔分别松开对位后再锁紧。远离主板的另一对孔此次不固定。
4. 602060电池按含保护板与出线的20×80×8毫米空间从开放面放入，两侧保留间隙；接触边缘加薄绝缘保护。两条软绑带穿过侧梁窗口轻固定，只作防脱，不勒紧软包，出线端保持敞开。

另预留五个直排针焊孔和两个M2固定孔，供同一块摇杆小板以后与主板平行安装，现弯针装法继续保留。备用固定孔一圆一短槽，孔距19.5毫米；备用针序按翻转后的模块连接，不能照搬原针排顺序。完整模型仍只装一块摇杆，备用孔不装器件。未来M2×10从元件面向摇杆侧穿、螺母在摇杆侧，避免螺纹伸入陀螺仪小板。

完整装配包含真实PCB铜层、排针、焊点、绑带及七根手焊线；同名源板与制造包已同步单行元件布局和备用孔。E盘旧嘉立创原生工程未随本轮修改。模型检查验证名义实体、安装与运动空间，不能代替实物试装。
