# 第二代开放工程样机

当前装配以拇指所在一面为操作面：HW-504摇杆、电池托和一体底座放在这一面；SuperMini开发板、陀螺仪及主板其他元件放在相反一面。摇杆轴平行主载板，原生帽沿整机 +Z 朝天空。电池所在的下半段作为握持位置，不增加塑料扳机、摇杆帽或外部限位圈。

摇杆外形按 [DZYJ尺寸图](../器件资料/原始资料/HW-504双轴摇杆模块_DZYJ尺寸图.jpg) 的标称值建模：黑板33×27毫米，安装孔距26.4×19.5毫米，原孔直径3.3毫米，含原生帽总高约30毫米。图注尺寸误差0.5～1毫米；轴心、排针弯角和帽形仍为外形示意。

靠主板的两个安装孔以19.5毫米间距固定在一体底座的两根短柱上。使用两颗 **M2×10螺丝和普通M2螺母**：螺丝从短柱下方向上穿，螺母放在摇杆板上方压住原孔，**不需要新增垫片**。塑料座一孔为2.4毫米圆孔，另一孔为沿孔距方向的2.4×3.6毫米短槽，便于试装。摇杆保留原有弯排针，五针的新载板孔位留待结构确认后调整。

旧的摇杆绑带小托已取消。底座连接梁绕开黑板、原生帽和运动空间，上横梁移到靠主板的一侧，给拇指从上方接近帽子留空，不构成额外限位。模块相对电池中线向前偏4毫米，用于让开既有螺柱及工具位置。底座只有一个打印实体，约12.0克树脂；不是实物称重。

靠拇指进入方向的H2固定柱改为贴近主板的短柱，含螺钉头向拇指侧凸出约6.7毫米，比原来少约11毫米；连接梁也改走靠板的一层。仍保留四孔固定，H2使用M2×10，其余三处继续用M2×20。

载板小元件由15颗减为8颗：取消摇杆按下及右键的外置上拉/消抖电容两组，以及外部供电检测的三颗；保留扳机两颗、触摸串联电阻、摇杆两轴电容和电量采样三颗。小元件通孔1.1毫米、铜焊盘直径2.6毫米，电阻脚距7.62毫米、电容脚距5.08毫米；重新排布拉开元件间隔。程序保留估算电量显示，取消低电量自动休眠与外部供电识别。

## 装配

1. 载板H2短柱用一组M2×10与M2螺母固定，另外三处用M2×20与M2螺母；SS-01GL继续用原来的两组M2×20和原有垫片，直接操作其金属摆杆。
2. 开发板与GY模块从摇杆相反一面插焊，板间留3毫米。SuperMini两排中心距仍是用户同意的暂定15.24毫米；模块背面B+/B−保留两根短线。
3. 摇杆放在两根短柱上，用两颗M2×10由下向上固定，上方轻锁M2螺母；两孔分别松开对位后再锁紧。远离主板的另一对孔此次不固定。
4. 602060电池按含保护板与出线的20×80×8毫米空间放在薄托内，铺软绝缘垫，用两条软绑带固定，出线端保持敞开。

当前以查看装配结构为先；换面后的引脚对应关系、摇杆新五针孔和布线尚未同步到实际载板，旧打板包未更新。本次模型检查只验证名义实体、安装与运动空间，不能代替实物试装。
