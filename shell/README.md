# 第二代：开放工程样机固定底座

这一版只新打印 **1 件底座**，不做握把、左右包覆壳、塑料扳机、摇杆帽或外部摇杆限位。载板、开发板、陀螺仪模块和电池外露；握持形状先用纸壳试。现有 **SS-01GL 金属摆杆扳机继续用**，两根软线连接载板，不换 SS-01GLD、不专门开槽。普通电源拨动开关直接焊在载板上，电池两根线焊到 `J_BAT`。

## 打印文件

- [engineering_mount.stl](stl/engineering_mount.stl)：这一版唯一必需的新打印件，已转为平底朝下、毫米单位，100% 尺寸打印。
- [engineering_mount.step](step/engineering_mount.step)：同一底座的可编辑实体，保留整机装配坐标。
- [right_cap.stl](stl/right_cap.stl)、[right_cap.step](step/right_cap.step)：第一代右键帽原文件，尺寸与字节均未修改。默认直接按原生右键按钮；本底座没有为帽子另做防脱框，原帽只保留为可选参考，不保证直接套上就能可靠操作，也不需要重新打印。

底座名义约 **78 × 129.8 × 28.1 毫米**，实体体积约 **11.5 立方厘米**，按树脂密度 1.2 估约 **13.8 克**；不含绑带、螺丝、电子件和打印支撑。向下的一段只是电池薄托，不是握把。载板外形和四个固定孔未改，摇杆轴心仍是整机坐标 **X=-33、Z=23 毫米**，周围没有限位圈或覆盖面。

选韧性树脂或尼龙。普通脆树脂的高柱和陀螺仪托在装配中容易被掰断；支撑不要落在载板柱顶、模块边托、SS 螺母槽和绑带槽内。固定孔为名义间隙孔，首件仍要检查收缩、毛刺和实物配合，不强拧扩孔。

## 固定和装配

沿用已有 M2×20 杯头内六角螺丝 **6 颗**、M2 螺母 **6 个**：4 组夹载板，2 组固定 SS。载板正面螺母直接轻夹，不为这四处额外买特殊垫片。另用 SS 原有 M2 薄垫片填平侧面间隙、四条窄软绑带（电池两条、开发板一条、陀螺仪一条）和薄绝缘软垫。

**先试装再焊长线。** 底座是一体件，陀螺仪托在载板上方，因此载板和开发板不从正上方直接落入：

1. 开发板保持原朝向：元件面朝载板元件面的同一侧，USB-C 朝枪口前方，陶瓷天线朝后。不装长排针，背面焊点和软线总占位不超过 2 毫米。比最终座位抬高约 5 毫米，从 USB 前方沿底座滑入，再落到两条边托上；原生 USB、按键和天线露出。用窄软绑带固定，绑带不要压连接器、按键、芯片或焊点，实际位置按手头模块空白边调整。
2. **尚未安装 SS 和 GY 模块时**，载板比柱顶抬高约 2 毫米，从底座下边方向滑到四孔上方，再落到柱顶。摇杆已焊好也不经过限位孔。四颗 M2×20 从底座背面向载板元件面穿入，正面轻锁螺母；H1 上方有 GY 边托，螺母从前侧横向放入。底座背面用 1.5 毫米内六角扳手拧螺丝，正面用薄钳扶住螺母，不把载板压弯。
3. 电池包络沿用原版：含保护板和出线不大于 **31×52.5×8 毫米**。薄托上先铺柔软绝缘垫，放入电池，两条软绑带穿槽固定。只收紧到不晃动，不勒凹电池；电池不承担握力，不让焊脚或螺丝抵到电池。电池线留卸力余量，再焊 `J_BAT`，极性以载板丝印和接线表为准。
4. SS-01GL 放在一体两孔座上。开关本体与座之间的名义间隙为 0.6 毫米，可先沿用每孔两片 0.3 毫米垫片，再按实物厚度调整，两孔同侧垫片总厚一致。不要靠拉弯塑料座填间隙。两个 M2 螺母从底座侧槽放入，M2×20 从开关外侧穿入锁紧，多余螺杆藏在底座柱孔中。直接按金属摆杆；原生推钮、铰接和摆杆全行程保持空旷。COM 和 NO 各一根软线接 `J_TRIG`，NC 不接；先用万用表确认端子。
5. GY 模块保留原位置、元件朝向和坐标轴方向，放到集成边托上，使用绝缘软垫和软绑带固定。绑带走空白板边，不压芯片或焊点；模块不得晃动。不要用方向不明的旋转安装代替。
6. 原触摸电极移到 SS 金属摆杆：**薄绝缘胶带 → 铜箔 → 薄绝缘胶带**。铜箔只接 `J_TOUCH/1`，不接 SS 的电气端子或地。导线避开铰接和推钮，留出按下与回弹余量，并在底座附近卸力。贴好后验证完整按下、松手回弹、触摸门限；金属底层会改变触摸电容，需要实测调整。

板载电源开关、电池永久焊接、电源与 USB 的接法，以 [载板说明](../pcb/README.md) 为准。没有新增外置电源开关壳。

手握先用纸板和绝缘胶带做薄套，只包住需要握的边和焊脚面；不要把电池当握把捏，也不要用手掌挤压陀螺仪、开发板焊点或金属摆杆。先找合适的宽度、角度和手指位置，后续再决定握把形状。

## 文件核对的边界

[assembly-check.json](assembly-check.json) 来自 [生成工具](../tools/build_gen2_mount.py)，核对名义实体有效且只有一个连通体、与器件/焊脚保守包络的干涉、上述直线装配路径的连续包围盒、6 组紧固件及螺母槽/轴向工具空间，以及打印网格闭合与体积。模块位置沿用第一代数据；不是对用户实物的测量结果。

首件还需实物核对：器件批次尺寸、绑带落点、树脂收缩和强度、SS 手指可达与回弹、摇杆全部方向及中键、触摸门限、模块稳固程度、无线连接和电池温升。预览中的器件是保守外形示意，柔性金属摆杆并非原厂动作模型。
