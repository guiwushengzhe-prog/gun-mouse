枪型飞鼠控制

通过这台电脑的蓝牙，连接你身边的飞鼠。设置保存在飞鼠中，关闭网页后仍保留。

连接飞鼠

未连接

先在 Windows 中配对“GunMouse SuperMini”，再用 Edge 或 Chrome 打开本页。首次连接需要在浏览器弹窗中选择飞鼠。

尚未连接设备。

如果列表找不到已配对的飞鼠，可让飞鼠关机再开机后重试。此页控制当前电脑附近的设备；飞鼠尚未直接联网，离开蓝牙范围后无法远程控制。

连接期间每秒刷新。实际触摸门限同时考虑基线比例和噪声保护，因此可能高于设定比例。断开后读数会清空。

电池连接点是开关后的采样电压，不能代替电池两端的实测。现有载板没有接入充电状态反馈，因此回报“未知”，不按电压猜测充电或充满。

飞鼠设置

摇杆

接线核对正确后，松开摇杆让它回中，再启用。启用会自动取中心；摇杆按下为鼠标中键。

体感方向与灵敏度

只调整陀螺仪带动光标的方向，摇杆方向保持原设置。

触摸开关

触摸控制模式下，触摸决定体感能否移动；常开模式免触摸。开启比例应高于关闭比例；提高比例会更难触发。此处显示设备正在使用的比例，不自动替换已有设置。

重取基线前正常握住设备，手指离开铜箔和裸露感应导线，保持约半秒。当前使用铜箔检测。

校准

先将飞鼠放稳，再点击校准，保持静止约 3 秒。这里只校准传感器零点，保留已保存的左右方向校正。

本次操作

连接后可操作。状态回报固件会核对摇杆开关、速度、中心和体感灵敏度，并显示设备实际返回的结果。
