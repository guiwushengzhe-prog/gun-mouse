# 枪型飞鼠主站控制页

入口：https://guiwu-aware.icu/ota-admin/gunmouse.html ，沿用主站登录。

在 Windows 的 Edge 或 Chrome 中打开，先完成系统蓝牙配对，再点“选择并连接飞鼠”。浏览器只能连接当前电脑附近、用户选择授权的飞鼠；首次授权后可通过“重连已授权飞鼠”连接。飞鼠目前没有直接联网，不提供跨地点远程控制。打开页面不会自动改设置或升级固件。

## 支持的操作

| 操作 | 3.2.1状态回报固件的确认方式 |
| --- | --- |
| 查看触摸原值、基线、噪声门限与左右校正 | 蓝牙实时读取，每秒刷新 |
| 左右与上下反向 | 发送后检查设备回读一致；不会自动重复切换 |
| 保存开启与关闭比例 | 校验范围与先后顺序，逐条发送后回读两个值 |
| 摇杆启停、重新取中心、摇杆速度 | 检查执行序号以及开关、中心修订号或速度回读，另显示中心异常而暂停的状态 |
| 体感灵敏度 | 检查执行序号和实际灵敏度回读 |
| 陀螺仪零点校准 | 确认校准命令执行，实时显示传感器是否已就绪，不混用触摸就绪标志 |
| 触摸基线校准 | 保留原提示与操作，本次不修改触摸逻辑 |
| 电池连接点采样与充电状态 | 回报开关后的采样电压；没有充电反馈线，显示未知，采样偏高不等于电池实测过压 |

连接时使用设备名称过滤，而不是只按自定义服务过滤：现有3.2广播只包含鼠标服务，控制服务通过浏览器额外服务权限访问。读回必须具有枪型飞鼠身份；进入错误设备、未连接、升级中、断线后均禁用设置。断线清空旧读数。只在用户点击时发送设置，不开机扫描循环、不写新固件，不发送恢复默认参数命令。

3.2.1新增独立的扩展只读回报，避免原升级状态超过单个蓝牙属性512字节的上限。网页每秒依次读取基础与扩展状态，方向、开关、速度等命令在3.2.1上同时检查执行序号，避免同值设置未执行却显示成功。兼容原3.2没有扩展回报的情况，会明确提示需要更新固件，不能把命令送达当作设置确认。

网页沿用现有站点策略，使用外部脚本和样式，不新增后端、匿名接口或保存主站凭据。电脑蓝牙命令由浏览器直接发送，不经服务器转发。原有陀螺仪第22版与麦克风的脚本、固件和更新接口保持。

## 验证

在本目录运行 `node test-control.mjs`，验证设备身份、噪声门限、参数范围、固件逐条保存顺序与回读边界。

`browser-check.js` 配合浏览器自动化命令的 `run-code --filename` 使用，预览根目录为上一级 `web`，预览地址为 `http://127.0.0.1:18764/ota-admin/gunmouse.html`。脚本在浏览器中模拟蓝牙，只用于界面与协议检查；不能当作真实蓝牙兼容或用户手感验收。

线上静态文件在 `/var/www/guiwu-aware/portal/ota-admin/`，只增加四个控制页支持文件，并在原首页增加入口。部署前检查原首页、应用脚本和样式校验值，备份首页后逐文件原子替换，入口最后发布。无需重启网站服务。

## 甩拳调节（2026-10-27）

原页新增“甩拳模式”，点“连接甩拳控制”读取本机 MotionControl 的设置和事件计数。可开关、选设备、调强度和冷却并保存，还可让本轮显示归零。参数保存在软件统一配置中，和电脑端同步；计数归零不改软件累计，软件重启后累计重新开始。按键仍在软件的“本游戏 → 飞鼠甩拳”选择，不新增一份网站绑定。

此模块不另建蓝牙连接、不直接向设备写甩拳参数，避免与软件每5秒续期互相覆盖。原方向、摇杆、触摸与灵敏度继续使用网页蓝牙入口。软件需保持运行，使用 Windows Edge 或 Chrome，并允许本站访问本地网络；打开页面不会自动连接或更改设置。

软件精确允许主站来源访问三个飞鼠接口：`/api/gunmouse/status`、`/api/gunmouse/config`、`/api/gunmouse/devices`；不开放其它接口。线上仅飞鼠控制页的内容策略增加到 `http://127.0.0.1:8766` 的连接，主站登录不改。网页支持模块为 `gunmouse-punch.js`，验证脚本 `browser-check-punch.js` 同样使用模拟接口，检查保存、失败补存、计数、断线及窄屏。

页面级策略片段为 `gunmouse-punch.caddy`，加入现有主站静态处理段，校验后平滑重载；不替换主站其余配置，也不移除原登录。
