# 枪型飞鼠主站控制页

入口：https://guiwu-aware.icu/ota-admin/gunmouse.html ，沿用主站登录。

在 Windows 的 Edge 或 Chrome 中打开，先完成系统蓝牙配对，再点“选择并连接飞鼠”。浏览器只能连接当前电脑附近、用户选择授权的飞鼠；首次授权后可通过“重连已授权飞鼠”连接。飞鼠目前没有直接联网，不提供跨地点远程控制。打开页面不会自动改设置或升级固件。

## 支持的操作

| 操作 | 现有3.2固件的确认方式 |
| --- | --- |
| 查看触摸原值、基线、噪声门限与左右校正 | 蓝牙实时读取，每秒刷新 |
| 左右与上下反向 | 发送后检查设备回读一致；不会自动重复切换 |
| 保存开启与关闭比例 | 校验范围与先后顺序，逐条发送后回读两个值 |
| 摇杆启停、重新取中心、摇杆速度 | 命令送达，但3.2不回报这些设置，需实际试用 |
| 体感灵敏度 | 命令送达，但3.2不回报此设置，需实际试用 |
| 触摸基线和陀螺仪零点校准 | 提示对应动作；不将触摸就绪标志当作陀螺仪校准完成 |
| 充电状态 | 当前硬件没有反馈，明确显示无法读取 |

连接时使用设备名称过滤，而不是只按自定义服务过滤：现有3.2广播只包含鼠标服务，控制服务通过浏览器额外服务权限访问。读回必须具有枪型飞鼠身份；进入错误设备、未连接、升级中、断线后均禁用设置。断线清空旧读数。只在用户点击时发送设置，不开机扫描循环、不写新固件，不发送恢复默认参数命令。

网页沿用现有站点策略，使用外部脚本和样式，不新增后端、匿名接口或保存主站凭据。电脑蓝牙命令由浏览器直接发送，不经服务器转发。原有陀螺仪第22版与麦克风的脚本、固件和更新接口保持。

## 验证

在本目录运行 `node test-control.mjs`，验证设备身份、噪声门限、参数范围、固件逐条保存顺序与回读边界。

`browser-check.js` 配合浏览器自动化命令的 `run-code --filename` 使用，预览根目录为上一级 `web`，预览地址为 `http://127.0.0.1:18764/ota-admin/gunmouse.html`。脚本在浏览器中模拟蓝牙，只用于界面与协议检查；不能当作真实蓝牙兼容或用户手感验收。

线上静态文件在 `/var/www/guiwu-aware/portal/ota-admin/`，只增加四个控制页支持文件，并在原首页增加入口。部署前检查原首页、应用脚本和样式校验值，备份首页后逐文件原子替换，入口最后发布。无需重启网站服务。
