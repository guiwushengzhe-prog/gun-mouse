# 枪型飞鼠：电路板与外壳

本项目先搭建可通过程序调用的电路板与外壳设计工具。实际硬件方案和外形尺寸待用户提供后确定。

- 项目与版本管理：`F:\项目\枪型飞鼠`。
- 工作树（同一个版本库的独立工作目录）：项目内的 `.worktrees`。
- 软件安装：在 `E:\各种软件` 下新建目录。
- 优先路线：支持命令行的新版本嘉立创专业版负责电路板，CadQuery 负责通过代码生成外壳，Miniforge 提供独立运行环境。
- 自动化验收：通过程序读写设计、执行检查、导出文件，并验证两侧共用的板形、孔位与坐标。
- 工具验证用的示例不代表实际飞鼠设计，不是可下单生产的产品。

工作进展和遇到的问题追加到 `docs/工作记录.md`。
