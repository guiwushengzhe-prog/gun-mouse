普通 PS2 摇杆、TTP223 模块、700mAh 电池、充电升压板没有仅凭这些名称就能套用的统一整件尺寸；芯片、针距和插口标准不能代替整件资料。SS-01GL 则有完整型号的原厂轮廓图，可以按图做名义候选件，最终支架仍须匹配实物后缀。

当前低成本触摸原型采用 SS-01GL、铜箔电极和已有 TTP223，两路分别负责机械左键与触摸启停；是否直接贴在隔绝缘的金属柄上或加小打印帽，尚未冻结。详细来源、待测项和方案判断见 `../docs/器件参数与待实测清单.md`。
