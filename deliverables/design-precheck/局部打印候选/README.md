# 两处局部装配优化候选

对应正式维护分支的原六件打印包。本目录只包含右半壳和扳机的替换候选，不是可直接下单的整套定稿。原打印件、主板布线和器件位置未被覆盖；扳机与右键的全公差问题仍需另行解决。

- `右半壳-摇杆支撑候选.step/.stl`：在摇杆背面增加直径 5 毫米柱，中心 X=-32.5、Z=26.0，名义端面 Y=-3.33，距原板背面留 0.1 毫米。已检查保存的装配主板实体无正体积干涉。真实板厚、柱高和打印误差还需确认，不能靠螺丝把过高的柱压下去。
- `扳机-端接避让候选.step/.stl`：电极上沿增加局部接头腔和引出空间，面盖后该局部的名义深度从约 0.15 增到 1.0 毫米。其余感应面仍保持平整，原面盖、滑杆、触点尖端和硬限位不改。希望使用工厂已端接的软线，用户只插接；接头与绝缘固定样件仍需确认。

STEP（实体交换文件）保留整机坐标；STL（三角网格打印文件）按原推荐姿态摆放。两个候选均为有效单实体，打印网格单连通、无开放边、无非流形边、无零面积面；这证明文件可用于后续打样检查，不证明实际打印配合或强度已验收。详细数据在 `候选几何检查.json`，支撑局部检查在仓库 `evidence/design-review-v1/支撑柱局部干涉.json`。

配置为 `config/装配优化候选.json`，生成入口为 `scripts/design_review/build_local_candidates.py`。整体设计判断见 `docs/设计预审与优化决策-V1.md`。
