## 开关和模块怎样接

所有焊接在拔出电池、断开 USB、开发板未插入主板时完成。你需要焊的是开关两根线、模块四根线与一根短接线；不需要手焊裸陀螺芯片或 0402 小器件。若触摸电极尚未预制，另做其线端连接。

开关只用 **COM（公共端）和 NO（常开端）**：接到主板 J4 的两根线。J4 的 1 脚是扳机信号、2 脚是地；机械开关两根线互换不影响通断。NC（常闭端）不接，焊片包绝缘。先用万用表确认：放开时断开，压杠杆时导通。按开关端子标注识别，不能把“中间脚”一律当公共端。

模块必须接其“芯片接口”，使用下表，不能接成模块处理器输出模式：

| 主板 J1 焊盘 | 模块端 | 功能 |
| --- | --- | --- |
| 1 脚 | 1 脚 VCC | 3.3V 供电 |
| 22 脚 | 2 脚 GND | 地 |
| 15 脚 | 3 脚 SCL | 时钟，接开发板 IO9 |
| 12 脚 | 4 脚 SDA | 数据，接开发板 IO8 |
| — | 模块 5 脚 SA0 短接模块 2 脚 GND | 固定地址 0x6A |
| — | PS 模式脚悬空，6 脚 CS 保持模块原上拉 | 直接使用芯片接口 |

线焊在 J1 **背面的较大通孔焊盘**，不要塞入排母插孔。J1 从 1 脚朝 22 脚数，1 脚在枪前端天线一侧；先数脚并量地线，不凭照片猜方向。GY 模块自身已有数据和时钟上拉，所以主板 R10/R11 留空。

模块芯片元件面朝整机左侧，与主板元件面同向；长边沿枪前后，模块 1 脚在枪的前下角。先在壳外焊好线，再夹入左壳定位轨，压框箭头指向枪前，用两颗 PA2×10 螺丝轻拧固定。不能让模块在壳内晃动。支架按模块 17.8×20.6 毫米外形、板厚 0.8～1.6 毫米设计；正面排针突出不超过 6 毫米、背面不超过 4 毫米，不加杜邦插头。实物超出这些范围需调整支架，不能强压合壳。

四线先在主板背面沿排母下方向后汇合，再从板下缘绕到模块；开关线和触摸线沿各自槽走，给扳机保留活动余量。看 `装配说明图` 的位置图，不把线束压在滑轨、壳缝或螺柱上。

## 装配和首次使用

1. 单独给开发板烧入本目录 `固件/gun_mouse.ino.merged.bin`，再拔下开发板准备装配。它是原工程样的同一份程序，本轮未改固件。
2. 焊好模块和开关线。把 SS-01GL 用两颗螺栓装到专用支架，直摆杆朝扳机；支架滑入原小板位置的卡槽。开关底面、两个安装孔和杠杆端点按支架定位，不能换方向装。
3. 右壳内放电池、支架、弹簧和扳机，主板放到五个定位孔，插好 J4 和触摸线 J5；铜箔位于扳机触摸面盖下面。
4. **合壳前设定扳机触点**：先拔掉 J4，万用表蜂鸣档跨接开关两线。把 1.0 毫米设定片夹在滑杆后端与弹簧座之间，压住扳机；从浅到深调 M2 触点，刚导通即停止。松开后重新压 0.8 毫米片应导通，重新压 1.2 毫米片应断开。每次由完全松开开始，避免开关回差影响判断。具体螺栓边界及测量位置见 `扳机装配与调整.md`。
5. 抽出设定片，确认没有片时扳机按到底导通、放开断开、能回弹，再插回 J4。装右键帽、模块左壳，布好线并合壳，装摇杆帽。合壳后复查一次触发和复位。
6. 插电池前核对 J3 的 1 脚 BAT+ 是正极、2 脚是负极。电池端子线不同店家可能相反，不能只看插头可插就接。
7. 开电源，手指离开扳机、摇杆回中，把飞鼠放稳约 3 秒完成启动校准。电脑蓝牙添加 **GunMouse EVT-A**，然后即可按下表使用。

| 手上的动作 | 鼠标动作 |
| --- | --- |
| 手指轻贴扳机，不压机械开关 | 启用体感移动，不点击 |
| 摸着扳机转枪、抬头低头 | 光标随转动移动 |
| 扣下扳机 / 一直扣住 / 松开 | 左键按下 / 保持按下 / 释放 |
| 松开机械扳机，手指仍轻贴 | 左键释放，体感仍启用 |
| 手指离开触摸面 | 体感停止，清除积压位移 |
| 侧面右键帽 | 右键 |
| 按摇杆 | 中键 |
| 推摇杆 | 移动光标，偏得越多速度越快 |
| 同时推摇杆和转枪 | 两路位移相加 |
| 插拔充电线 | 不自动暂停鼠标操作 |

正常闲置不自动睡眠；低电量且未插 USB 时会按原程序进入休眠。首次确认方向、触摸门限和速度可通过串口设置保存：`log` 看状态，`jdir` 标定摇杆方向，`jsave` 保存范围，`invx/invy` 反转体感方向，`sens 数值` 调速度，`tp/tr` 调触摸门限。

程序烧录路径和原文件校验在 `固件/固件文件校验.json`。Windows 上用原来的烧录工具把合并文件写到地址 `0x0`，先选实际开发板端口；底部充电口兼有下载布线，但其实际下载可靠性尚未验收。开发板插在主板上时，不同时连接开发板自己的 USB 电源口。
