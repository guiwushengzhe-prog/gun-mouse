# SuperMini 开放骨架：装配与首件检查

这套实验件用于正常单手握持、移动和按键操作。结构允许电路板外露，以前后握把梁、横桥和局部机构承担握力。电路采用 ESP32-S3 SuperMini 和现成模块，模块间由人工焊线连接。

当前原位模型的[完整 CAD 验收](generated/assembly-check.json)已通过：4 个载板安装点、14 颗螺钉及其螺母、38 个运动状态、13 条装入路径、5 项线束/绑带包络；另有扳机 4.1 mm、右键 0.8 mm 连续行程、触点全调节与行程组合、摇杆全方位 20°及最差 0.9 mm 中按的包络检查。整套紧固件为 M2×10 七颗、M2×20 七颗、M2 螺母十五枚。这些结果针对报告中的名义尺寸、保守包络和装配阶段，不替代实物配合、开关动作和握持检查；外置 SPST 尚未建模，按下述首样流程核定。

## 工具和紧固件

使用之前的 M2×10、M2×20 **杯头内六角机螺钉**（DIN912 / GB70.1 / ISO4762），长度从头下量起，配标准 M2 六角螺母。工具为 1.5 mm 内六角扳手。固定螺钉杯头包络按 Ø4.0×2.1 mm 检查；螺母参考对边 4.0、厚 1.6 mm。实际螺钉、螺母先测量，确认能够装入预留孔和螺母槽。

另备尖口钳、细锉或砂纸、卡尺、万用表、焊接工具、薄型 4 mm 螺母扳手（厚度不大于 1.8 mm）及 0.8 / 1.0 / 1.2 mm 校准塞片。塞片可以使用量具，厚度需实测，误差控制在 ±0.05 mm。

## 装配顺序

1. 对照打印件清单分离零件。先剪断停车区的连接桥，再修平连接点，保留导轨、压板接触面、螺母槽、摇杆孔和帽沿限位面的尺寸。检查梁根、螺母座及连接点无裂纹。
2. 先空装螺钉和螺母，确认螺母可以从侧窗进入、防转且可以取出。孔内残料用合适工具清理；机螺钉拧入螺母，不靠强拧扩孔或在树脂上攻牙。
3. 按载板图准备手工焊接母板、模块和线束。在装入电池前完成焊接、绝缘和板外通电检查。元件和导线只占据配置允许的安装空间，连接头与焊点的实际突出量也计入；板背焊脚按配置修到不超过 1 mm。**C_RAIL 陶瓷电容在焊前将引脚成形，使本体向 -X（远离 H4 螺母）偏移至少 0.3 mm**，焊盘位置不变；复查电容与 H4 螺母有可见间隙，不受螺母挤压，安装高度仍不超过 7 mm。SuperMini 与 GY 直接焊柔性线，去掉超高排针，不装未经包络验证的杜邦插头。
4. 从 +Y 侧试放电池。含保护板、外皮和线头的实测尺寸不超过 8×31×52.5 mm；薄软绑带与托边限制移动，不将电池压紧到主板焊脚上。线头向预留出线口，避免夹在骨架、滑轨或螺柱下。将成品带线 SPST 的绝缘本体用两根小扎带绑在后底梁外侧，避开电池、掌心接触处和可剪桥残根，导线固定卸力；开关本体尚未建模，这一步须以实物核对，不强塞入电池仓。
5. 主载板仍留在外面，暂不装 SuperMini 压框；从骨架的 +X 侧横向放入 SuperMini 与软线，落在板边支撑上。确认背部软线没有夹在支撑下面，再装压框和两颗 M2×10。前角止挡随可拆压框装上，由止挡与压框保持模块；USB 端和天线端按配置留空。SuperMini 必须先于主载板安装。
6. 将载板从 +Y 侧放到四个定位柱。此时 GY 模块、开关支架、扳机侧门和控制压桥都未装，导线暂时放到插入路径外。核对 H3 在 X=-51、Z=-4，所有孔自然对正，不能靠把载板拧弯来补孔位偏差。暂定位载板，控制压桥稍后安装。
7. 先从 +Y 侧放入独立 `imu_cradle` 托座，再放入 GY 模块，最后装其压框和两颗 M2×10。托座随这两颗螺钉一起固定；托座板边止挡与压框限制脱出，压框避开元件与焊点。主载板装入时，GY 托座和模块都必须留在外面。
8. 在机外先按 COM / NO 焊好 SS-01GL13 两根 26AWG 软线并绝缘，NC 留空；从焊片的 +Y 侧焊接并转向 +Y，将焊包、热缩与走线留在 X=[-24.2,-21]、Y=[0.3,2.3]、Z=[-21.2,-0.5] 的预留空间，不弯折焊片根部。将开关装入打印支架，按实测间隙放 M2 薄垫，名义每孔每侧两片 0.3 mm；可用 0.1 / 0.2 mm 调整片补齐，两孔同侧等厚。轻拧两颗 M2×20 后开关应贴面稳定，不靠拉弯树脂墙收紧。螺钉在机外拧好，将开关、支架、螺钉、螺母与垫片整件从 +Y 侧插入槽；长螺钉尾端由骨架遮挡。随后放入复位弹簧和扳机。为避开释放位的名义贴面，扳机连同调节螺钉与螺母先沿 -X 后退约 **0.15 mm**，从 +Y 侧将滑杆落入导轨，再沿 +X 释放回位；这段位移处于原有 4.1 mm 行程内。保持 +Y 侧门未装以便校准。
9. 在机外预装右键帽：先将帽子沿 -Y 比释放位置下移 **0.15 mm**，保持这个姿态从控制压桥的 +X 开口横向滑入 U 形导向槽。侧滑时后法兰与导向槽留 0.15 mm、前帽沿留 0.65 mm。横向到位后，再沿 +Y 回位 0.15 mm；这是自由零件的两段摆放路径，无需用力挤过法兰。随后装一颗从底侧沿 +Z 穿入的 M2×20 和 M2 螺母锁住出口。头下座位为 X=-24.9、Y=18.8、Z=-11.4，螺母位于 Z=6.5–8.1，工具从 -Z 底侧接近。螺钉作为防脱挡杆，不夹死帽子，帽子沿 +Y / -Y 应能按压和复位。螺母从侧窗装入，确认不掉出。此螺钉在控制压桥落位前装好。
10. SS-01GL13 的 COM / NO 两根线接载板 `J_TRIG` 的 GND / TRIG；NC 不接。按下文校准扳机，合格后用两颗 M2×10 装 +Y 侧门。全行程手动检查回弹、前后硬限位和防脱。必须先装好侧门，再将带防脱挡杆的控制压桥装到骨架上，保持侧门的 +Y 插入路径畅通。
11. 安装带右键帽的控制压桥，以及 H1、H4 两个独立载板压片。四颗 M2×20 均从背侧穿入载板定位柱；H2、H3 的压紧位置在控制压桥上。分次均匀拧紧，板稳定即可，握力与按键力应传到骨架支撑。
12. 校准后接触摸线。铜箔只接 `J_TOUCH` 的 `TOUCH_ELECTRODE`，另一 GND 焊点是备用或屏蔽，不接同一铜箔，闲置线端绝缘。导线沿预留槽走，全行程应有活动余量，不能牵拉电极端接或进入滑道。用薄胶层固定触摸面盖，确认铜箔、胶层和线头一起能放下。
13. 最后对准摇杆轴削边装帽子；最短、最长轴按首件尺寸检查帽子高度与止挡，配合过紧时记录尺寸，不强压开关或轴。再按 [载板焊线表](pcb/PCB-manufacture-notes.md) 和 [固件说明](firmware/README.md) 复核全部线路。测量电池极性后接电池，同名端子也以实测正负为准。

SuperMini 本版电池正极经过外置开关后接专用 B+ 焊盘，负极接 B−；关闭开关会断开电池与充电回路，USB 仍可能供电。连接电脑 USB 前先关电池，拔 USB 后再开电池。充电使用已通电的独立 5V 电源适配器，电池开关置 ON；断开或关闭适配器前先关电池，保持 BOOST 跳线开放。电池开关 OFF 但 USB 插着时，B+ 读值是空载充电器输出，不能当作真实电池电量。实际板型、充电电流和到货测量见 [电源核对](research/supermini/power-and-pin-review.md)，首次烧录见 [固件说明](firmware/README.md)。

## 扳机校准

调节头端面是扳机触点，M2 螺距 0.4 mm，一圈改变 0.4 mm，八分之一圈改变 0.05 mm。校准范围以本实验的机构配置为准。全程断电，用万用表蜂鸣档检查开关的公共端与常开端。扳机处于机内时，开关挡住普通内六角扳手的轴向工具路径；采用**取出调节、放回测量**的方式。

已装完的整机需要重新校准时，先取下控制压桥连同右键帽及防脱挡杆，再拆 +Y 侧门；保留 H1、H4 压片定位载板。校准后按侧门、控制压桥、摇杆帽的顺序恢复。柔性线束需留服务余量，不通过扭掰骨架取出扳机。

1. 从 +Y 侧窗口装入固定螺母和前侧锁紧螺母，再穿入 M2×10 调节螺钉。先不锁紧，不装 +Y 侧保持件，也暂不接触摸线。
2. 将弹簧、扳机放回导轨。将 1.0 mm 塞片放在滑杆后端面与弹簧座之间，避开弹簧；从完全释放状态压到塞片处，检查通断。
3. 完全释放，取出塞片。轻按使扳机沿 -X 后退约 0.15 mm，再从开放 +Y 侧取出扳机和弹簧，不撬导轨。在机外用普通 1.5 mm 内六角扳手调节触点，按装配第 8 步放回后重复第 2 步。最终一步从不导通的一侧调向开关，刚导通就停，以处理开关回差。
4. 再次取出扳机，用内六角扳手保持螺钉位置，用薄型 4 mm 扳手将前侧螺母锁紧到后侧固定螺母。放回扳机和弹簧。
5. 换 0.8 mm 塞片，从完全释放状态压到塞片处，必须导通；换 1.2 mm 塞片，从完全释放状态压到塞片处，必须不导通。
6. 取出塞片，无塞片按到底应导通，松开应立即断开。安装 +Y 侧保持件、接触摸线，再复查两个塞片判定与正常回弹，确认设定没有变化。

硬限位承担到底后的压力。校准失败时记录实测动作位置和打印尺寸，调整机构，避免以继续挤压开关代替止挡。微动附近不使用瞬干胶或螺纹胶。

## 首件检查

| 项目 | 方法 | 判定 |
| --- | --- | --- |
| 拆装 | 完整拆装一次 | 电池、载板、模块和螺母可取出；不强塞、不磨电路板 |
| 正常握持 | 单手握持、移动、按全部按钮和摇杆 | 接触圆角骨架；电路板边缘、焊脚和电池不承受握力；无裂纹或永久变形 |
| 保持 | 倒置、轻晃，再插拔 USB | 电池、载板、模块、帽子不脱落，机构校准不变化 |
| 扳机 | 校准塞片复查，轻侧触上导轨，再反复正常按压与释放 | 每次触发、回弹；上导轨无明显挠曲或夹滞；导线不夹擦；硬止挡承载 |
| 右键 | 正常按压，再压到帽沿止挡 | 每次触发、释放；载板不明显弯曲，帽沿承担额外按压力 |
| 摇杆 | 四周摆动与中按 | 无元件干涉，帽子不脱出，局部限位与背部支撑工作 |
| 电路与触摸 | 按当前固件说明上电、配对、校准 | 扳机左键、右键、中键、摇杆与触摸控制均符合固件说明 |
| 充电 | 按电池与充电模块参数核对电流并测温 | 极性正确，电池不受挤压，实际温度低于电池允许值 |

上述首件检查用于正常操作，不包含摔落、冲击或过度挤压。CAD 检查与模型估重、实物的配合与称量分别记录。
