# 当前内部布局原型图

日期：2026-10-05。当前方案：ESP32-S3内置触摸＋铜箔＋SS-01GL，普通PS2摇杆；不装TTP223、AT42QT1011或轨迹球。

本轮重点是内部组件与安装关系，外形沿用已有方向。三张图共用同一布局：

1. [内部布局透视](A-内部布局透视.png)：主控、天线、摇杆、惯性模块、微动、电池和电源安装区域。
2. [分解安装关系](B-分解安装关系.png)：左右壳、各局部支架和模块的关系，开壳维护与可换摇杆座。
3. [触摸扳机与线束](C-触摸扳机与线束.png)：铜箔直接接S3电容触摸、微动独立输入，活动引线与电源线路分开。

开发板与惯性模块使用资料名义尺寸，SS-01GL采用对应原厂参考；摇杆和电池为具体其他厂家资料的参考区域，不代表用户实物。电源、右键和支架是待定设计区域。图中线束、接头、螺丝和细节均为表达，不是最终型号或安装孔。

原图`../v2/C-触摸与机械点击分开检测.png`中的独立触摸检测板已取消；新图与当前配置为准。参数化布局配置和解释见 `../../config/internal-layout-v1.json`、`../../docs/内部布局原型-V1.md`。

三张解释图通过内置图像生成工具制作，完整输入及修正记录见[生成说明](生成说明.json)。为避免效果图细节被误认为加工依据，同时提供由统一配置直接生成的[左侧占位图](参考-左侧占位.png)、[三维占位图](参考-三维占位.png)、[三维占位文件](内部布局占位.step)和[规划盒报告](占位检查报告.json)。其中透明壳为外形包络，不是可打印外壳；规划盒总宽49毫米也不是已测得整机厚度。
